# 另行补齐的密钥与私有样本清单（只含名称/用途）

本页没有读取任何密钥值，没有打开私有样本、证书文件、真实.env或用户凭据。不得把本页变成填值表；所有值由用户/运维通过获准私密渠道另行补齐，不放仓库、聊天日志或模型输入。

| 名称或类别（仅标识） | 用途与交接要求 |
|---|---|
| AIA_SECRETS_DIR | 仓库外secret目录位置；接班在新环境独立配置，不复制个人目录路径或登录态 |
| APP_MASTER_KEY / app_master_key | 应用派生加密/HMAC；既有数据必须使用原匹配密钥，不能重新生成替代；仅按部署允许服务挂载 |
| data_licence_seal_public_keys / data_licence_seal_private_keys | 每用户数据证书HPKE封装/解封；公钥供API/ingest，私钥仅ingest；原数据需匹配版本 |
| DATA_LICENCE_SEAL_KEY_VERSION | 新封装所用版本标识，不是私钥；与保留私钥版本对应 |
| POSTGRES_PASSWORD | 数据库属主凭据，仅迁移/建角色等管理用途，不交业务进程代用 |
| db_password_aia_api / db_password_aia_ingest / db_password_aia_maint | 业务、采集、专用删除维护的分角色口令；以当前secret文件机制交付，不在环境全集/日志中暴露 |
| DATABASE_URL / REDIS_URL / AIA_MAINT_DATABASE_URL_FILE | 服务连接/维护DSN文件引用；可能含凭据，只按服务边界装配，不写入手册；维护明文DSN环境变量不可替代指定文件机制 |
| 每用户麦蕊数据证书 | 在本人设置页受控录入、加密入库；账号与授权重新核实，不共享证书或猜用户归属 |
| MAIRUI_MODE / MAIRUI_REPLAY_DIR / MAIRUI_EGRESS_IP_EXPECTED | 回放/真实模式、合成回放位置和唯一获准出口约束；不属于证书值；未审批保持replay/闭锁 |
| MAIRUI_LICENCE | 已废弃全站变量，服务启动若发现非空应拒绝；不是接班要补进部署.env的凭据；独立实测必须另外获批 |
| DEEPSEEK_API_KEY | 获准机械任务的模型服务凭据；本任务禁止使用且未读取其值；不授予产品/安全结论外包权限 |
| 其他模型路由凭据 | 解释网关未来受控调用用，未启用时模板兜底；不得复制旧账户token/浏览器会话 |
| SMTP_PASSWORD及邮件配置 | 仅未来明确获准的邮件渠道使用；交接不启动外发，不迁移地址或真实收件记录 |
| 管理员登录/注册邀请 | 接收方自己的受控账号及角色；无原账户自动继承，不在本文记用户名/密码，不代用户G7确认 |
| 受控成交明细样本 | 导入解析、费用/数量勾稽、编码/列头兼容验证；仅保留“成交明细”类别，不复制真实账户/股东代码/委托编号/金额 |
| 受控资金与持仓快照样本 | 现金/可卖量/持仓重建与对账验证；仅记类别，不抄真实证券组合、账户、余额或样本文件名 |
| 数据库备份与imports卷备份 | 恢复不可变事实与加密导入文件；另需原密钥的私密备份，二者分开保存，不随文档入库 |
