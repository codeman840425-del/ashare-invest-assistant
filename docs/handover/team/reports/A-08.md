# A-08｜runner 三件套结构自描述：trials.csv / legs.csv / summary.json（判读与复核共用）

依据：冻结代码 `src/backend/retest/t_r58/`（outputs.py / runner.py / sim.py / experiments.py / judgement.py，@ds-T-B136-r2 工作树）。本文只描述 writer 实际输出，不改代码；列名以 `TRIAL_FIELDS`/`LEG_FIELDS`/`SUMMARY_FIELDS` 为准。

## 0. 发布机制（读件先读这节）

- 一次 run = 一个目录，**同文件系统原子 rename 发布**（`_publish`）：`<run名>/`（成功）或 `<run名>.failed/`（拼接/格式失败，只含 failure.json，无部分结果）。发布前有 `.<run名>.publishing` 锁目录，异常中断后锁残留、run 名不可复用。
- 成功目录固定四件：`trials.csv`、`legs.csv`、`summary.json`、（有 vipdoc 盘点时）`vipdoc_single/`+`vipdoc_main/`（各含 filelist.csv + SHA256SUMS）。CSV 为 UTF-8、fsync 落盘；summary 为缩进 JSON。
- writer 强校验：行键集 ≠ 字段表全集 → 整个发布失败（列不会被静默增删）。

## 1. trials.csv（每参数组合×相位一行）

| 列 | 语义 | 单位/取值 |
|---|---|---|

| segment | 该相位覆盖的段名 `seg1/seg2/...`（`/` 连接） | 字符串 |
| start / end | 相位首/末交易日 | ISO 日期 |
| params | 参数字典 JSON（sort_keys） | 见 §3 |
| holm_family | 是否参与 Holm 多重校正族 | bool；仅 `training_final` 为 true |
| n | 该试验的**全部 trial rows（腿）数，含未了结腿**——勘误 2026-11-11 R-07 二次发现：源码 `_stat` 直接对 `trial.rows` 全集统计（runner.py L212-215），未按 exit_date 过滤；对账与 P4 坏退出占比计算**不得以 n 为分母缩掉未了结腿**（未了结腿的 pnl 仍参与均值与自助 CI） | int |
| mean_bp | 腿均值 | bp（1bp=0.01%）of notional |
| ci_low_bp / ci_high_bp | 块自助置信区间（bootstrap_block/reps、按相位种子可复现） | bp |
| selected | 走查选择标记 | bool |
| status | 试验状态（正常/跳过等执行状态，非判读结论） | 字符串 |

## 2. legs.csv（每腿一行；判读的最细粒度）

| 列 | 语义 | 单位/取值 |
|---|---|---|
| trial_id / group / segment / exchange / symbol / board | 归属与证券 | symbol 无后缀 6 位；board 由交易所规则推出 |
| entry_date / exit_trigger_date / exit_date | 入场日/离场触发日/实际离场日（exit_date 可空=未了结） | ISO 日期 |
| direction | 方向 | `sell_first`（先卖后买）/ `buy_first`（先买后卖）；方向集在训练窗口冻结（P10） |
| data_source | 腿两端的行情来源 | `HF`（≤2026-08-06）/ `vipdoc_single`（08-07）/ `vipdoc_main`（≥08-10）/ `cross_splice`（跨拼接点腿，两端不同源） |
| trigger_slot / entry_slot / exit_trigger_slot / exit_slot | 触发/入场/离场触发/离场的分钟槽（0 基，240 根/日） | int；入场=信号后下一根开盘（fill_delay） |
| entry_price / exit_price | 成交价（不复权原始价，qfq 由 gbbq 自算仅用于可比性检查） | 元；exit_price 可空 |
| reason | 离场原因 | **源码实际枚举（sim.py `_leg` 路径，勘误 2026-11-11 R-07 发现）**：`revert`（回归回补）/ `stop`（止损）/ `time`（到 time_stop 未触发的顺延了结）/ `deferred`（跨日顺延至次日后了结、含尾盘收尾）/ `unvaluable_exdate`（跨除权不可估值）/ `unvaluable_embargo`/`unvaluable_end`（段界/停牌等不可估值边界）。~~time_stop/last_fill~~ 为文档初稿笔误，源码无此二值；P4 判定（judgement.py L282-284）按 `time`/`deferred`/`unvaluable_*` 前缀计坏退出 |
| q / notional / planned_amount | 股数（整手约束后）/ 名义本金 / 计划成交额 | 股 / 元 / 元 |
| participation_pct | 参与率（拟成交额÷近 20 有效日日均成交额） | %；停牌日不计，可空 |
| impact_bp_frozen | 冻结的冲击成本档位 | bp（I1–I5 分档，按参与率） |
| theta / sigma / dev / vr | 入场时阈值 / 当日累计波动σ / 触发偏离 / 量比 | theta、dev 为比例（0.012=1.2%）；vr 为 Decimal 串可空 |
| commission / stamp / transfer / slippage / impact | 逐项成本 | 元；佣金含 5 元下限；印花税 0.05%（2023-08-28 后）或 0.1%（前）按日分段 |
| pnl_yuan / pnl_bp | **实际执行净盈亏**（含全部成本、按整手与冲击档） | 元 / bp of notional |
| cons_pnl_yuan / cons_pnl_bp / cons_mark_price | **保守口径**盈亏（保守标记价，用于稳健性对照） | 元 / bp / 元可空 |
| prior_anomaly / exec_anomaly | 入场前当日有异常 bar / 入场执行 bar 异常 | bool（数据质量旗标，判读时异常腿单独计） |
| hold_bars | 持有分钟数 | int 可空 |
| mae_bp | 持仓期最大不利偏移 | bp |

**R 组（随机对照）不在 legs.csv**：R 组按腿聚合为 `RLeg{entry_day, direction, mean_bp, mean_cons_bp, n_ok}` 存于试验内存、直接进 judgement 的 P5 配对（每腿 ×20 次抽样均值，n_ok 应= r_draws）。判读 P5 用 summary.criteria.P5.paired；B-01（efbe652）已补 R 对照逐腿证据落盘。

## 3. params 字典（A/B/C 三形）

`A`：`{group:"A", k, floor, revert_band:0.5, stop_mult:1.5, trend_abs_pct:0.05, min_edge_cost_mult:2.0, entry_start:"09:45", entry_end:"14:30", time_stop:"14:50", last_fill:"14:56", confirm:2, sigma_warmup:30, commission_rate:0.00025, notional:50000, fill_delay:1, directions:[sell_first,buy_first], v:null}`（k=floor 网格点位；比例小数）
`B`：同上但 `group:"B"`、`d` 固定阈值替代 k/floor（k=null、floor=0）
`C`：在 A* 或 B* 基础上加 `v`（量比过滤档），group 改 `C`
敏感性与 P8 变体：只改 notional（10000 等）或 commission_rate，name 带 `notional_`/`commission_`/`p8_` 前缀。

## 4. summary.json（**至少 10 个顶层键**；`SUMMARY_FIELDS` 为强制下界，允许额外键——勘误 2026-11-11 R-07 发现）

writer 校验为 `summary.keys() >= SUMMARY_FIELDS`（超集放行）；judgement 返回还会追加 `holdout_by_source`、`multiplicity` 等键，有 vipdoc 盘点时另有 `vipdoc_date_inventories`。强制下界十键：

| 键 | 内容 |
|---|---|
| plan | 方案标识（retest_plan 版本） |
| data | 输入证据：hf/vipdoc 快照 sha256、revision、日界、股票池规模（`stock_pool`）、日历 |
| segments | 各段（fold）起止/embargo 证据；保留集两段分列 |
| checks | **L1–L14** 检查结果（判读红旗 R0 的输入）+ `bar_quality`；L2/L3/L5/L6/L8/L13 带 `state:"runtime_asserted"/"no_eligible_legs"` 与腿计数；L9 带逐 ST 状态剔除 `status_by_year`；L12 诊断性（unvaluable_exdate 腿数）；L14 splice 覆盖 |
| splice | 拼接校验结果（④①–④、重叠一致率、双包一致性） |
| exclusions | 剔除账本（按年的 ST/退市/新股/停牌计数） |
| delisting | 退市股核验（P9 证据） |
| criteria | **P1–P10 判定对象**：每个为 `{status: pass/fail/unknown, ...detail}`；P3 带 `average_cost_bp`、P5 带 `paired` 配对统计、P7 带按年 up/down 环境分组分、P10 带 `directions`（训练窗冻结的方向集） |
| seed | 全链随机种子（bootstrap、R 组抽样共用相位种子，可复现） |
| conclusion | `{status, promote:false, reason}`——**promote 恒 false**：判读层只给 eligible_for_review / not_passed / data_insufficient / scope_unresolved 四态，晋级永远另走人工链 |

（强制下界即上表十键；`holdout_by_source`、`multiplicity` 为 judgement 常规追加键，读数时按存在性取用，不得假设固定键集。）

**判读锚**：`criteria.P*.status` 三态；`holdout_by_source`（拼接口两段分列）在 judgement 返回内、随 summary 一并落盘；结论状态机：P1 样本不足 → data_insufficient；P9 缺证 → data_insufficient；任一必过项 fail/unknown → not_passed；P8 边界未解 → scope_unresolved；否则 eligible_for_review。

## 5. 复核要点（与 RV 清单对齐）

1. 列集自证：任何 run 的 CSV 表头必须逐列等于 §1/§2 表（writer 硬校验，多余/缺失即发布失败）。
2. 原子性：不存在部分结果目录；`.failed` 目录只有 failure.json（blocked+stage+kind）。
3. 可复现：同 seed + 同输入 sha256 → 同 trials/legs 数字（bootstrap 与 R 组均按相位种子）。
4. `promote` 字段恒 false 是设计约束，判读不得改写。
