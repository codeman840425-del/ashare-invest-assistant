# G-7：/imports、/trades 的 ?account_id= 非本人账户 → 404（后端）

- 来源：T-live-83a031c.md §8.4。B 用户 `GET /imports?account_id=<A 的账户>`、`GET /trades?account_id=<A 的账户>` 返回 200 + 空列表；契约 §7.5/§7.6（v0.2.9 #27 ⑦，T-B46 裁定）要求 `404 NOT_FOUND`（与 /portfolio 一致）。
- 提交：**ab84776**（pathspec：`src/backend/app/api/v1/imports.py`、`src/backend/app/api/v1/trades.py`、`src/backend/selfchecks/g7.py`）。未 push。
- 改法：两个列表在带 `account_id` 时先调用 `app.api.v1.accounts.owned_account`（与 `/portfolio`、`POST /imports` 同一个函数）——不存在 / 不属于本人 / 已归档 → `404 NOT_FOUND`，错误体与其他账户类 404 完全相同（不区分三种情况，不泄露账户是否存在）。
  - 保守读法：已归档的本人账户也 404（与 /portfolio 相同；目前 API 没有归档入口）。如架构师认为已归档账户的历史应可查，需改为只校验 user_id。
  - /imports：校验放在游标解析之前（404 优先于 INVALID_CURSOR）；/trades：在同一只读连接中、security_code 规范化之前。
- 自检：`env -u MAIRUI_LICENCE PYTHONPATH=$PWD .venv/bin/python selfchecks/g7.py`（隔离 PG/Redis）→ **22 passed, 0 failed**：
  - B 查 A 的账户、随机 uuid：/imports 与 /trades 都 404 NOT_FOUND，error 字段集合与 /portfolio 的 404 相同，不返回 items；
  - A 查本人账户 200；不带 account_id 200；非 uuid → 400 VALIDATION_ERROR；未登录 → 401。
- ruff check / format、mypy strict 通过。tester pytest 全量未在本次重跑（被中断），只跑了自检。
