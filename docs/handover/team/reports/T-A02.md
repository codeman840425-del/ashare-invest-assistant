### 1.5 契约 v0.2.1 → v0.2.2（变更记录已加）
- `RuleRef.passed: boolean | null`，语义统一为“表达式求值为真”（veto/counter/invalidation/weakening/exit 为真 = 命中）。
  - 无法求值时为 `null`。
  - 未持有时，ctx/plan 规则不出现。
- `rule_ids_passed` 只列 `passed == true` 的规则。
- P1b（`PLAN_REQUIRES_EXPLAINABLE_SIGNAL`）：要求至少有一条 role ∈ {entry, exit, weakening} 且 passed = true 的规则。
- `DimensionCell.rules_passed/rules_total` 和 `key_evidence_ids` 只统计 role ∈ {entry, filter, hold}。
- `/horizon-assessments`：
  - `scores` 必须四个周期都有，int 0–100，不为 null。
  - `reasons[]` 加 `horizon` 和 `polarity`。
  - 新增 `inputs_missing: string[]`，用来区分“真 0 分”和“缺数据被封顶”。
- `refs[].ref` 是出处编号，与列表项里的 `ref: <rule_id>` 不同义，两者都保留。
- `oos_result` 确认为 `string | null`。
- G-01 中有对应原因码的检查项（停牌、一字涨停、ST/退市整理、新股）只产出不可执行原因，不把 state 改成 `vetoed`；低价股仍为 veto。
- `/reconciliation` 的成本口径计入分红。
- `/meta/enums.version` 改为 `"v0.2.2"`。
