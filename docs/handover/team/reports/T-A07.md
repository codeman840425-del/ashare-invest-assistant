## 1. 结论

- **推荐**：`data_sharing.mode=per_licence`（默认）。每位用户只用自己的证书取数，只看自己证书取到的数据；不回退到他人或管理员的证书。
- **合规判断**：
  - 每人自用证书按条款字面**基本合规**。前提是证书以朋友本人账号申请。代运营和同 IP 多证书两点【待麦蕊书面确认】。
  - 全站共用一份（`shared_cache`）按服务条款 2.1(5) 字面属于“再次分发/交由第三方使用”，**不合规风险高**。标【待麦蕊书面确认】，书面答复前禁用。

## 2. 设计要点（详见 plan 2.1B）

| 方面 | 决定 |
|---|---|
| 存储 | HPKE（RFC 9180 Base：X25519 + HKDF-SHA256 + AES-256-GCM）。`api` 只有公钥（只能加密），私钥 `DATA_LICENCE_SEAL_PRIVATE_KEYS` 只给 `ingest`。AAD 绑定 user_id、row_id、key_version。不用 `APP_MASTER_KEY`，因为 api 持有它。明文不经 Redis |
| 防重 | `licence_hmac`（HKDF(APP_MASTER_KEY,"data-licence-dedup-v1")），在未删除行上唯一 → `409 DATA_LICENCE_IN_USE` |
| 不回显 | 任何响应都不含证书值、末位或指纹；`api` 库角色对 `ciphertext` 无 SELECT，只读视图 |
| 日志 | URL 中的证书段改成 `***`；`ingest` 对已加载明文做字符串替换；api 请求体日志对 `licence` 字段脱敏；Sentry 也过滤 |
| 校验 | 16–64 位 `[A-Za-z0-9-]`【待核实 T-B05】，拒绝 `/ ? # %` 和空白 |
| 调度 | 每证书一个令牌桶，默认取官方档位的一半：钻石 3000、包年 1500、包月/体验 500、免费/其他 150。接口级限额也按证书计数。每证书有 P0>P1>P2 三个队列。证书之间先比优先级，同级按 DRR 轮转（quantum 1）。每证书并发 1；全局并发 2【待 T-B05】。熔断按证书，全部证书同时失败才全局熔断 |
| 网络 | 一个固定出口 IP。60 秒 2-IP 规则按证书执行；朋友的证书不离开生产；开发只能用用户本人证书，并走“后台暂停 → 等 60 秒”流程 |
| 降级 | 102→`invalid` 停止；101→`quota_exceeded` 暂停到次日 00:01；103/429→`ip_limited` 暂停 120 秒，1 小时内 3 次→暂停 1 小时并通知；频率 503 退避 1→60 秒，连续 5 次熔断 300 秒；数据缺失型 503 不熔断；过期→钻石版按每日额度只保留 P0。用户侧看到 `data_status` stale/unavailable 加 `gaps.data_licence_unavailable` 和横幅；写操作返回 `409 DATA_LICENCE_UNAVAILABLE`。到期前 30/7/1 天提醒（到期日由用户填写） |
| 成本 | 额度不是瓶颈（每证书约 400 次/分钟，上限 3000）。瓶颈是串行时延 0.26 秒/次。默认“全市场快照 60 秒 + 重点 ≤20 只 15 秒”，每证书 5–30 次/分钟。盘后批量只取用户自选与持仓，否则 10 张证书要 10–15 小时 |
| `MAIRUI_LICENCE` | 生产和预发不再使用；`ingest` 发现它非空即拒绝启动。只有本机实测可以在用户本人 shell 中临时设置 |

### 3.2 每人自用（per_licence）
最接近“申请账号自行使用”。剩余风险：
- ① 证书若登记在用户名下再给朋友用，可能被认定为转让或交第三方使用。应以朋友本人账号申请，用户可以代付。
- ② 用户的服务器代朋友调用其证书（托管），条款未明确【待麦蕊书面确认】。
- ③ 同一 IP 跑多位持有人的证书【待麦蕊书面确认】。
- ④ 派生统计也只用本人证书的数据计算。

### 3.3 共享一份（shared_cache）
A 的数据给 B 看，按字面属于再分发，即使 B 也买了证书。成本约为 per_licence 的 1/用户数，但这不能作为启用理由。

### 3.4 建议用户书面询问麦蕊（QQ 3826425416 或 linkmeans 企业顾问表单，保留记录）
1. 我为几位朋友各买一张证书，以他们本人账号申请，由我的服务器代他们调用、只给证书持有人本人看。这样是否允许？
2. 同一台服务器（同一出口 IP）同时使用多位不同持有人的证书，是否允许？“60 秒 2 个 IP”是否按证书单独计算？同 IP 并发有无限制？
3. 用 A 的证书取到的行情（含派生指标）缓存后，展示给同样持有证书的 B，是否允许？
4. 如需书面授权或企业版，范围与费用如何？
5. 接口能否查询证书档位与到期日？

另外，每人自用证书**不解决**以下问题（见 plan 7.1–7.3、问题 48）：
- 交易所行情授权；
- 投资咨询资质；
- 朋友的敏感个人信息。
