## 2. 实现说明

### 2.1 配置（`app/config.py`）
- `Settings` 冻结、忽略未知变量、大小写不敏感；**不读取 `MAIRUI_*`**（licence 只属于 ingest）。
- 来源优先级：构造参数 > 环境变量 > `CONFIG_DIR/*.yaml`；**不启用 dotenv**（`.env` 只给 compose 插值，T-O01 约定）。
- YAML：只读 `CONFIG_DIR` 顶层 `*.yaml|*.yml`，按文件名（stem）放进 `settings.business`；不递归（`strategies/` 留给策略模块）；解析失败、顶层非映射、同名 stem → 启动即失败（`ConfigError`）。
- 主要变量：`APP_ENV`(local/test/staging/production)、`SERVICE_NAME`、`LOG_LEVEL`、`API_PREFIX`(默认 `/api/v1`)、`DATABASE_URL`(SecretStr)、`REDIS_URL`、`HEALTH_CHECK_TIMEOUT_S`(1.0)、`INGEST_HEARTBEAT_KEY`/`INGEST_PAUSED_KEY`/`INGEST_STALE_AFTER_S`(120)、`APP_MASTER_KEY`(SecretStr；非 local/test 必填；≥32 字符)、`PAGE_LIMIT_DEFAULT`(50)/`PAGE_LIMIT_MAX`(200)、`CURSOR_TTL_S`(86400)、`CONFIG_DIR`。
- **config/ 目前只有 `strategies/`，没有任何顶层 yaml。待办（交给配置/对应模块负责人，按 plan 命名）**：`realtime.yaml`、`ingest.yaml`、`market_rules.yaml`、`risk_controls.yaml`、`horizon_classifier.yaml`，以及是否需要 `app.yaml`（非敏感应用参数）。骨架在没有 yaml 时正常启动（`business={}`）。

### 2.2 统一错误（`app/common/errors.py`）
- 外壳严格按契约 §2：`{"error":{"code","message","details","request_id"}}`，`details` 无内容时为 `null`；响应头同时带 `X-Request-Id`。
- 每个错误码的 HTTP 状态取契约 §4 原值；`IMPORT_ROW_COLUMN_MISMATCH` 标记为 `scope=row`（只出现在导入行结果里，`AppError` 拒绝用它做 HTTP 错误）；`SIGNAL_NOT_EXPLAINABLE` 标记为 `scope=internal`。
- 校验错误（FastAPI 422）统一改为 **400 `VALIDATION_ERROR`**，`details={"fields":[{"field","issue"}]}`；`field` 去掉 query/body/path 前缀，`issue` 规整为 `must be <= 200`、`must be >= 1`、`required`、`must be an integer`、`unknown field` 等（与契约示例 `limit` 一致）。
- Starlette HTTPException 映射：400→VALIDATION_ERROR、401→AUTH_REQUIRED、403→FORBIDDEN、404→NOT_FOUND、**405→NOT_FOUND（返回 404）**、409→CONFLICT、422→VALIDATION_ERROR、429→RATE_LIMITED、503→MAINTENANCE；其它 4xx→VALIDATION_ERROR、5xx→INTERNAL_ERROR 并记 warning。
- 未捕获异常 → 500 `INTERNAL_ERROR`，响应不含异常内容，完整堆栈只进日志（带 request_id）。

### 2.3 request_id
- 读取请求头 `X-Request-Id`：匹配 `^[A-Za-z0-9._:-]{1,128}$` 原样透传，否则生成 `req_<uuid4 hex>`（契约示例风格）。
- 存入 contextvar 与 `request.state.request_id`；写响应头；错误体 `request_id` 与响应头一致。
- 纯 ASGI 实现（不缓冲 SSE）；每请求一行访问日志：方法、路径（不含查询串）、状态码、耗时、request_id；uvicorn 自带 access 日志关闭（其不含 request_id）。
- nginx 已向上游注入 `X-Request-Id: $request_id`（32 位 hex），实测被透传，前后端日志可串联。

### 2.4 游标分页（`app/common/pagination.py`）
- 参数：`limit` 默认 50、最大 200（超出 → 400 VALIDATION_ERROR，`issue: must be <= 200`；<1 → `must be >= 1`）；`cursor` 不透明字符串。
- 游标：`base64url(JSON{v,s=scope,k=排序键,iat}) + "." + base64url(HMAC-SHA256 截断 128bit)`；密钥由 `APP_MASTER_KEY` 经 HMAC 派生；local/test 未设置时用进程内随机密钥。
- 篡改、跨接口（scope 不符）、别的密钥、过期（TTL 默认 24h）、格式错误 → 统一 400 `INVALID_CURSOR`（不区分原因）。
- 响应 `Page[T] = {items, next_cursor}`；`build_page` 取 `limit+1` 行判断是否有下一页。默认排序 `created_at desc, id desc` 由调用方在 SQL 中保证，键作为 `k` 存入游标（datetime 需转 ISO 字符串）。

### 2.5 `GET /health`
- 响应 `{status, db, redis, ingest}`，不需登录、不含细节；HTTP 恒 200。
- db：psycopg 异步连接执行 `SELECT 1`（自动把 `postgresql+psycop<path>` 转成 libpq DSN）；redis：PING；均有超时（默认 1s），并行执行。失败值为 `"error"`，异常类型只写日志。
- ingest（临时约定，待 ingest 落地对齐）：Redis `ingest:paused` 存在 → `paused`；`ingest:heartbeat`（Unix 秒）在 120s 内 → `ok`；否则 `stale`。
- `status` = 三项全为 ok 时 `ok`，否则 `degraded`。

### 2.6 `GET /meta/enums`
- 内容全部来自 `app/schemas/enums.py` 与 `app/common/errors.py`，路由不定义取值。
- 结构：`{"enums": {契约表名: [取值...]}, "reason_codes": [{code, release_kinds, check_on, manually_releasable, note}], "error_codes": [{code, http_status, scope}], "risk_control_labels": {值: "RC1".."RC6"}}`。
- `Cache-Control: public, max-age=300` + 强 ETag，支持 `If-None-Match` → 304；不分页、不需登录。

## 4. 契约不一致 / 歧义（均按最保守方式实现）

1. **API 前缀 vs nginx**：契约基路径 `/api/v1`；nginx `location /api/ { proxy_pass <url> }` 尾斜杠会去掉 `/api`。实现保持契约 `/api/v1`（`API_PREFIX` 可配）。需运维二选一：去掉 proxy_pass 尾斜杠（推荐），或给 api 设 `API_PREFIX=/v1`。
2. **405 无对应错误码**：§4 没有 METHOD_NOT_ALLOWED，现映射为 404 NOT_FOUND，不暴露 Allow 头。若契约要加专门错误码需修订。
3. **/health 失败取值与 HTTP 状态未定义**：契约只写 `db:"ok"`、`redis:"ok"`；实现失败为 `"error"`、HTTP 恒 200。需确认降级时是否返回 503、失败值叫什么。
4. **ingest 健康来源未定义**：临时约定 Redis `ingest:heartbeat`（Unix 秒）/`ingest:paused`，阈值 120s，键名可配；需 ingest（T-B04 系）确认。
5. **/meta/enums 响应外层结构未规定**：采用 §2.6 结构，请契约补充。
6. **大写枚举值**：`reason_code`（23 个）与 `gate`（G1–G7）为大写，与 §3"取值 snake_case"总规则冲突；按契约原表大写实现。
7. **DATA_STALE 同名**：既是原因码又是错误码（含义不同），前端需按字段区分。
8. **§3 未收录但其他章节出现的枚举**：如 health 的状态值、数据缺口原因（gap reason）、数据提供方（provider）——未加入 `/meta/enums`，需决定是否补进 §3。
9. **游标格式/TTL** 契约只说"不透明"，实现签名 + 24h TTL；过期也返回 INVALID_CURSOR，前端应重新从第一页取。
10. **T-B01.md 写"可直接推送（常设授权）"**与用户本轮"不要 push"冲突，按用户指令未推送。
