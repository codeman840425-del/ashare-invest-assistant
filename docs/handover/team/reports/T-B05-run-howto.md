# T-B05 用户电脑补测步骤

1. 核实用户授权、探针评审、允许运行的项目和调用上限；不要停止 v2 进程。检查共享与用户电脑的 STOP。仅可将已确认的旧 STOP 原样归档为 STOP.archived-<时间戳> 后删除。新 STOP 或 103/429 一律停止，不重试。
2. 用户电脑创建随机临时目录，仅复制探针脚本；先运行 run_all.py --dry-run，退出码必须为 0 且全部通过。
3. 证书默认只经环境变量使用。若已明确允许临时文件传递：共享电脑 umask 077，以重定向写入随机临时文件，不回显；CopyFromBox 复制到用户电脑临时目录后立即删除共享副本。
4. 用户电脑用 icacls 禁用继承，仅授权当前用户（需 M 权限以支持删除；只有 R 会导致 Remove-Item 失败，不能因此带文件开跑）；在同一 PowerShell 进程读取到 MAIRUI_LICENCE，立即删除临时证书文件，确认不存在后再启动探针。任何输出、命令参数、日志不得含证书值。
5. 使用本机直连（trust_env=False / --no-env-proxy），开跑前和跑完各检测出口，确认是同一个国内 IP。每次探针带 --check-egress，并核对与运行前 IP 相同。
6. 本次只运行 p13；再以 --p13-restated 600590.SH --p13-announce 2024-11-09 --p13-periods 2023-12-31,2024-06-30 运行 p13；最后运行 p12 --p12-only hslt。上限 28+28+1=57 次。不跑 p11、延迟、空值因子或未到期的历史复取。
7. 每次运行后检查 STOP、退出码和调用总数；出现熔断立即停止剩余项目。新的共享 STOP 也应立即停止运行。
8. 证书仍在环境变量时，运行 scan_licence.py 检查结果、样例和运行日志，必须未命中才能回传。打包回传到共享电脑 probes/results/<run-id>/ 等对应目录，保留原始结构。
9. 删除用户电脑整个随机临时目录，清除当前进程证书环境变量；确认共享电脑和用户电脑没有临时证书残留。共享电脑再用 scan_licence.py 扫描全部回传文件。
10. 简报调用数、熔断、国内出口一致性、结果路径、扫描和清理状态；V5i/V5j 取 analysis JSON，p12 核对 000016、301139、601059、601198。禁止提交、推送或改代码。例行任务须另有授权，不因本文件自动获得。
