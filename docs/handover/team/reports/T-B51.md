## 1. 结构（按 plan 4.6.2）
- `CREATE EXTENSION IF NOT EXISTS btree_gist`（降级不删扩展）。
- `securities`：加 `missing_since`、`last_seen_on`、`field_sources jsonb`；btree `(exchange, listing_status)`；删除 `ix_securities_name_norm_trgm`、`ix_securities_name_initials`（列保留）。
- `security_name_history` / `security_code_history` / `security_risk_flag_history` / 新表 `security_listing_status_history`：PK `(code, valid_from)`，`valid_from` 非空，`CHECK (valid_until IS NULL OR valid_until > valid_from)`，`EXCLUDE USING gist (code WITH =, daterange(valid_from, valid_until, '[)') WITH &&)`（约束名 `ex_<表>_period`）。name_history 删 `name_norm`/`master_source` 与 trgm 索引、加 `source`（szse_ssgsgmxx/exchange_diff）、`snapshot_id`、btree `(name)`；code_history 加 `valid_from`、`source`（bse_code_map）、唯一 `(old_code)`；risk_flag_history 加 `snapshot_id`；listing_status_history 的 `reason` 限 exchange_list/exchange_delist_list/missing_from_list。
- `master_snapshots`：source 限 10 个公开来源；`(source, sha256)` 唯一；sha256 须 64 位小写十六进制；`parse_status='ok'` 时 `reject_reason` 必须为空；btree `(source, fetched_at desc)`。
- `master_runs`：trigger 限 beat_1800/beat_0730/manual/bootstrap；`status` 运行中为 null；`snapshot_ids bigint[]`、`stats jsonb` 有默认值。
- `security_search_terms`：unique `(code, term_kind, term, source_name)`；btree `term text_pattern_ops`；gin trgm 仅 `term_kind in ('name','former_name')`（部分索引）；btree `code`；code 外键 `ON DELETE CASCADE`。
- `security_reconciliation_diffs`：开放差异部分唯一 `(kind, source, security_code, field, source_licence_id) NULLS NOT DISTINCT WHERE status='open'`；btree `(status, last_seen_on desc, id desc)`。kind/source 取值来自 `/meta/enums` 的两个枚举。
