### 合并规则
- `securities.code` 一律带交易所后缀（`600519.SH`），`code_history.old_code` 也带后缀。
- 当前名单优先于终止上市名单；终止日期在未来的不提前生效；深市 B 股不入库；上交所 689 段视为 CDR（待架构师确认）。
- 简称带"退" → `delisting_period` + 风险警示 `delisting`；`*ST` / `S*ST` → `star_st`；`ST` / `SST` → `st`（含全角）。
- 同一代码同一次运行出现在两所名单 → 不合并，记 `stats.exchange_conflicts`。
- 缺失：只看 stock / cdr 且为 listed / delisting_period 的证券；在 `last_seen_on` 之后该来源有 ≥ `missing_after_snapshots` 个**成功**快照日都不在名单，才改 `missing_from_list`（`missing_since` = 当天）；被拒收或抓取失败的日子不计数。重新出现即恢复 listed、清空 `missing_since`，写历史。
- 历史：值没变不写；同一天第二次变化就地改当天开的行；否则关旧行、开新行。深市简称历史按 SSGSGMXX 整体重建（首段从上市日开始，同一天多条取最后一条，相邻同名合并），风险警示历史随之重建（null = 摘帽，首段的 null 不写）。
- 北交所 2021-11-15 前上市 → `list_date_basis = neeq_select`。代码对照：新代码不在主数据则跳过；对照关系变化时删后重插，`valid_from` = 对照表的上市日期（待确认）。

1. 首次导入不调用 `reconcile_vendor`：代码里没有引用（自检 AST 检查），运行后 worker 队列和延迟队列都为空（自检运行时检查）。
