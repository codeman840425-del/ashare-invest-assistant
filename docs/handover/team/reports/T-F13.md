## 改动

| 项 | 实现 |
|---|---|
| 日期切换 | 新增 `useDailyReportPages`（`useInfiniteQuery`，按 `next_cursor` 逐页加载）。下拉末尾有“加载更早…”选项。增加“上一期 / 下一期”按钮：上一期不在已加载页里时，先加载下一页。当前日期不在列表里时仍会显示在下拉中 |
| 账户概览 | 对账标签显示 `diff_count` 和 `important_count`（“重要 N”）、`reconciliation.as_of`；状态为 `diff` 且有 `account_id` 时给出“查看对账 ›”，链接到 `/portfolio?tab=reconciliation&account_id=`（与 §5.1 reconciliation 路由一致）。参考区间注明“模板参数，不是指令”。仓位条位置限制在 0–100%，并加 `role=img` 和 aria-label。区间缺失时显示“参考仓位区间：缺失” |
| 无账户 | `account=null` 时显示“尚未导入交割单，账户概览为空”（`not_imported`）或“本期日报未关联账户”，并给出入口 `/portfolio/import` |
| 待处理 | 计数大于 0 时给出链接：计划草案 → `/plan-drafts?status=pending`，未解除原因 → `/candidate-signals?state=blocked`（见遗留问题 1） |
| 逐股卡片 | 有 `suggestion_id` 的卡片设为 `role=link`、`tabIndex=0`，Enter 或空格进入候选信号卡（`/suggestions/{id}`），聚焦时有描边。已移出或没有建议的卡片不可点击，也不可聚焦，并说明“已移出持仓与自选，本期不再生成策略结论” |
| 按变化筛选 | 用 Segmented 切换，由 URL `?filter=all\|changed\|unchanged\|removed` 驱动（changed = 新增 + 有变化），非法值按“全部”处理。每项带数量。筛选结果为空和本期没有证券分别有提示 |
| 免责提示 | `/daily-reports*` 是 ⚖ 接口，摘要下方固定展示 `CardDisclaimer`（与 disclaimer.md 逐字一致，测试比对） |
| 未知日期 | 显示错误框，并给出“查看最新一期日报 ›”（`/daily-reports`） |
| 常量 | `pages/dailyReportRoutes.ts`（`STOCK_FILTERS`、`PENDING_ROUTE`），供页面和测试共用 |

## 遗留问题

1. 契约没有规定日报 `pending.plan_drafts` / `pending.active_reasons` 的统计口径和前端去向。现按字面取最接近的列表筛选：`/plan-drafts?status=pending`（`/today` 的同类项用的是 `pending,stale`）和 `/candidate-signals?state=blocked`。建议契约补一张去向表（同 §7.3 “查看全部”）。这两个目标页目前仍是占位，在 T-F17 / T-F18 中实现。
2. plan 2.1 说账户层还应有“集中度”，但 §5.3 `account` 没有这个字段，所以未展示，也没有自定结构。
3. 日报列表接口没有按日期定位的参数。直接打开很早的日期时，下拉要一页页“加载更早”才能找到相邻期；当前日期本身总是可以选中的。
4. 契约 v0.2.8（6ef79c4）以及之后的 307132b（docs）未同步；本任务只按 v0.2.7 实现。
