## 5. 失败与复现
最终全部通过，无遗留失败。开发过程中遇到并已修复的问题：
1. **Playwright 配置报错** `ReferenceError: __dirname is not defined in ES module scope at playwright.config.ts:44`（package.json 设了 `"type":"module"`）。
   - 复现：用 `cwd: __dirname` 后执行 `pnpm -C tests e2e`。
   - 修复：改用 `fileURLToPath(new URL('.', import.meta.url))`。
2. **schemathesis ST204**：未声明的方法（TRACE）返回 404。
   - 修复：桩对已知路径的未声明方法返回 405，并带 `Allow: GET`。
3. **`pytest.raises(Exception)` 抓不到 schemathesis `FailureGroup`**：它继承 BaseExceptionGroup。
   - 修复：改为显式 `except FailureGroup`，再断言其中含 JsonSchemaError。
4. **回放 licence 正则漏判以 `"` 结尾的路径**：已补全并改为三引号 raw string。
5. **meta.json 的换行字段存在 `null`（空文件）与 “CRLF（末行无换行）”**：测试已兼容。
