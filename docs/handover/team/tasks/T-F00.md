# T-F00 可点击原型（前端）
- 目标：给用户看界面效果，确认风格和信息布局。原型用假数据，可以丢弃，不连后端。
- 依据：docs/plan.md §2.4 页面结构、§2.10 交易终端风格、§0A.2 建议必备内容、§2.5（维度×策略矩阵、分歧不合并、不可执行原因和解除条件）、docs/api-contract.md 的字段名。
- 页面（桌面 1440×900，深色、数据密集）：
  1. 交易终端主界面：自选/持仓表格（实时价、各策略动作徽标、分歧徽标、数据过期灰显）、K 线与分时并标出信号、通知角标。
  2. 建议卡/候选信号详情：六维度×策略矩阵、各动作并列、止损止盈、理由/反证/证据（时间和来源）、失效条件、风控标记、置信度、不可执行原因及解除条件、“生成计划草案”入口。
  3. 盘后日报：账户概览、逐股卡片、数据缺口提示。
  其他页面可以只放导航占位。
- 约束：放在前端目录下的独立原型子目录（不影响后续 T-F01 骨架）；技术栈与正式版一致（Vite+React+TS、AntD 暗色 compact、Lightweight Charts）；假数据明确标注“示例数据”；文案用“候选信号/计划条件”，禁用荐股措辞；不调用麦蕊。
- 交付物：构建好的静态包（dist，可直接双击 index.html 或用简单静态服务打开），以及每页 1440×900 截图 PNG 放在 /workspace/team/reports/T-F00/；在 /workspace/team/reports/T-F00.md 说明打开方式和设计取舍。
