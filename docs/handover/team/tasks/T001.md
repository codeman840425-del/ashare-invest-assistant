# T001 架构方案与接口契约
- 负责：架构师
- 状态：进行中（派发 2026-11-01 11:18 MDT）
- 目标：基于项目愿景和约束，产出 MVP 技术方案与接口契约。
- 输入：/workspace/team/vision.md ；麦蕊文档 <url>
- 验收标准：
  1. 推荐技术栈及理由（前端、后端、数据库、任务调度/提醒、部署），适合多用户对外网页版。
  2. 系统架构与模块划分，对应五种核心能力各自的 MVP 最小范围（做什么、不做什么）。
  3. 数据模型：用户、资产/持仓、观察列表、研究候选、行动计划（条件/依据/风险/失效条件）、提醒、交易记录、复盘；区分事实/估算/假设/实际成交，支持历史判断按原貌回看（版本或快照）。
  4. 麦蕊接口映射：每个能力用哪些接口、调用频率与配额估算、缓存策略；明确公告/新闻资讯的缺口与补充方案。
  5. REST 接口契约（路径、请求/响应字段、错误码），前后端可直接据此开发。
  6. 目录结构约定（后端/前端/tests/deploy 各自目录）。
  7. 风险与合规：数据再分发授权、投资咨询资质、个人数据保护。
  8. 分阶段实现任务拆分建议（含依赖顺序），供编排者派单。
- 交付物：/workspace/ashare-invest-assistant/docs/plan.md （可另附 docs/api-contract.md）
- 汇报：完成后向编排者汇报摘要和待用户决策的问题。
