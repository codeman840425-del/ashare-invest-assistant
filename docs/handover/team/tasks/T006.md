# T006 策略知识卡模板与首批策略清单（策略研究员）
- 目标：定出策略知识卡的标准模板，并列出 MVP 首批候选策略。
- 输入：/workspace/team/vision.md（策略库要求、三层结构、卡片字段定稿、可解释硬性原则）；架构师进行中的 docs/plan.md 与 docs/strategy-references.md（若已产出）；麦蕊能力待 T003 报告（/workspace/team/reports/T003-mairui-capability.md）。
- 交付物：
  1. docs/strategies/_template.md：知识卡模板，含全部定稿字段，每个字段写填写规范与示例；规则部分要能直接实现（公式、阈值、字段、边界）。
  2. docs/strategies/catalog.md：首批候选策略清单，覆盖四个周期和六个维度。每条写明一句话逻辑、所需数据（标“待T003验证”）、能否进入“可运行模板”的初判、主要风险，并给出 MVP 优先级。
  3. docs/strategies/validation.md：因子/事件/规则类策略的验证与健康度方法草案，包括与“用户端不做回测”的冲突说明和建议。
- 验收：字段与 vision.md 定稿一致；不编造麦蕊字段；结论由确定性规则表达。
- 约束：只写 docs/strategies/；不调用麦蕊。
