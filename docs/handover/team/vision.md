# 项目愿景（用户原文，2026-11-01）

让个人投资者在有限时间和可承受的风险内，持续做出有依据、适合自己、能够执行，并能从结果中学习的 A 股投资决策。

打造长期陪伴个人投资者的研究与决策助手：围绕用户的资金、持仓、关注方向、投资期限和精力投入，帮助发现机会、理解风险、管理持仓，服务个人资产长期积累。

痛点：信息分散且真假难辨；方法多难选择；研究结论难转成行动；持仓变化易遗漏；事后难分清结果来自判断、执行还是市场环境。

五种核心能力：
1. 看清当前处境：资产与持仓；市场/行业/公司重要变化；哪些已确认、哪些有缺口；与自己的关系。
2. 找到值得投入精力的机会：从方法找候选股票，也从感兴趣的股票找适用方法；每个候选说明研究理由、成立条件、主要反证、个人适配性；用户决定继续研究/加入观察/放弃。
3. 形成行动计划：做什么、为什么、何时行动、投入多少、承担什么风险、什么情况下改变判断；买入/加仓/持有/减仓/退出/等待各有依据。
4. 在需要时得到帮助：持续关注相关变化；提醒说明发生了什么、影响哪份判断或计划、现在需要核对什么。
5. 从真实经历中积累经验：把判断、计划、实际操作、后续结果连起来；保留当时已知信息；识别方法适用边界、执行偏差、反复出现的问题。

体验：轻松、连续、可追溯。打开即看到今天最值得关注的事项；可逐层查看依据、反证和原始资料；离开后回来能接续研究和计划。系统承担资料整理、重复核对、必要跟踪。

个性化基于用户确认的事实和偏好；资料不全时给范围清楚的帮助并指出哪些结论暂无法形成；方法分歧时解释分歧来源及什么新信息有助判断。

用户始终保有决策权：助手整理证据、计算、提出研究假设和行动选项；目标、风险取舍、真实交易由用户决定。个人资料由用户掌控；事实、估算、假设、实际成交清楚区分；历史判断能按原貌回看。

价值检验：是否更快理解重要情况、减少遗漏和无依据操作、更易遵守计划、能解释收益/损失来源、长期结果与承担风险和精力匹配。策略数量、信息数量、使用时长不能单独代表成功。

# 策略库需求（用户 11:38–11:41 详细确认）
- 持有周期：日内做T、短线(1–5天)、波段(几周到几个月)、中长线(半年以上) 全部兼顾。持仓导入后系统自动分析每只标的适合的周期与方法并给出推荐，用户可修改。
- 判断维度：技术面、资金面（主力资金流、龙虎榜）、基本面（估值/财务/成长）、情绪面（涨跌停/竞价/热度）、板块与大盘环境、消息面（公告/新闻）全部纳入，越详细越好。
- 信号矛盾：不合并结论，按维度并列展示各自观点、依据与分歧点，由用户判断。
- 风控（全部实现，用户可逐项开关）：每笔建议带止损/止盈价；单只仓位上限提醒；总仓位按大盘环境建议；板块集中度预警；连续亏损与回撤预警；违反自己计划时提醒。
- 模拟跟踪反馈：展示各策略胜率与盈亏供用户决定调整；同时支持自动降低表现差策略的推荐优先级，该自动调整可开关。

# 编排者向用户提出的策略库五层结构草案（11:49，供架构师参考，非定稿）
1 数据与指标层：统一口径的六维指标宽表（日终+盘中），分析/模拟/复盘共用，支持按时点回看。

4 匹配与建议层：按标的特征推荐周期与策略（用户可改）；六维并列展示不合并；叠加用户开启的风控。
5 跟踪与反馈层：建议落快照，跟踪 1/5/20 日表现，统计策略胜率与盈亏，可开关自动降权；关联实际成交用于复盘。

# 策略卡字段定稿（用户 11:52 提供 + 编排者补充）
用户表：身份(ID/名称/分类/版本/状态)；来源(项目/文章、文件位置、来源版本、授权)；假设(为何有效、什么证据否定)；标的范围(股票池/排除/流动性)；数据(字段/周期/复权口径/可得时间/更新要求)；选股(筛选/排序/入选数量)；入场(触发/确认时间/计划有效期)；退出(趋势失效/止损止盈/时间退出/再平衡)；仓位(单标的上限/策略预算/组合集中度)；验证(区间/基准/成本/样本外/交易明细)；运行(最近扫描时间/数据状态/信号与阻断原因)；复盘(信号表现/实际操作差异/失效记录)。
关键字段“不可执行原因”（信号成立但不生成计划）：数据过期；行业暴露超限；已有同向计划；交易状态不满足。
编排者补充字段：适用市场环境与风格及不适用时的处理；周期与扫描节奏；A股交易约束(T+1、涨跌停、停牌、ST、20%涨跌幅板块、北交所、竞价时段)；成本与滑点(可用用户真实费率校准)；信号强度与置信度(标注事实/估算/假设)；策略冲突与互斥及优先级；个人适配；参数范围与敏感性；审计与版本(旧版本信号可原样回看)；合规文案。
补充不可执行原因：涨跌停/停牌/ST；资金不足或T+1可卖不足；单标的上限或策略预算用尽；大盘环境不符；与已确认计划或禁投名单冲突；冷静期；连续亏损/回撤触发暂停；置信度低于阈值或关键数据缺失；非交易时段；用户手动屏蔽。每条不可执行原因需附“解除条件”。
- 硬性原则（用户 11:56 确认）：策略输出必须可解释，信号可追溯到规则、数据、数值、反证与失效条件；LLM 只做表述不生成结论；黑盒模型仅作辅助维度，不能单独触发计划。
- 性能（用户 11:55 关注）：避免 SQLite 后期变慢；业务库与行情时序库分离、指标预计算与缓存、前端按需分页。
