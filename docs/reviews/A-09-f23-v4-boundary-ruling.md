## 总裁定：标题发现 + 诉讼/仲裁离线五证裁决；仅该新增类别可凭冻结映射计数，其他观察类不新增计数，异常波动不设 policy

“其余观察类不入表”指不新增这些类别的 F23 计数资格；不清除任何既有独立风险命中。300169 型查封的研究候选与计数候选按 R3 明确区分。运行时读取标题与冻结公告 ID 映射，不在线抓正文或解析金额；离线证据只供冻结前裁决和复核。

按 R-01 §8 清单逐项：

### R1｜能力范围：标题链为主，重大诉讼/仲裁类批准「标题发现 + 结构化裁决」两段式；异常波动**不新增 policy**

- v4 线上事件发现仍走标题链；新增诉讼/仲裁的计数资格另查已离线核定并冻结的公告 ID 映射（N-01 的 10 日计数窗不引入正文抓取与金额解析到线上路径）。
- **重大诉讼/仲裁**：标题关键词（重大诉讼/重大仲裁/累计诉讼/累计仲裁）只作「发现层」——命中后进 `needs_evidence`，**不直接贡献 F23 计数**；升格为 `risk_candidate` 须离线人工核 R-01 §3.2 五条件（主体/身份/金额口径/PIT 分母/独立影响）并留证据记录。线上计数只包含已核 `risk_candidate` 集合（以公告 ID 锚定、同案去重），公告 ID 级映射表随 v4 词表一同冻结。
- **异常波动**：全部 `observe`，**不设下跌保守否决 policy**。理由：N-01 是买入 veto，误杀代价已由 T-A151 确认为高于漏报；下跌波动→基本面恶化是二级推断（波动可能是炒作回落、板块轮动），把它 policy 化等于用交易现象替代事件证据，会制造高频误报类（A股每日异常波动公告数量远超立案/重整类）。严重异常波动/停牌核查的交易状态处置归既有可交易性模块（G-01/susension 链路），不在 F23 重复。
- 同标题并列独立事件（V05 型）：`retain_existing_hit` 确认——异常波动标签不清除同公告的 insolvency/investigation 命中。

### R2｜金额与作用范围：接受 R-01 §3 全部口径，四条硬化

1. **板块/版本分流**照 S4/S5 原式，不跨板块搬用分母（L05/L06 对照成立）；深市/北交所无已核版本 → 该案 `needs_evidence`，不回退沪主板公式。
2. **边界值从严**：严格大于（L02 恰 1000 万 = 不达）、比例不四舍五入（L04 9.999…% = 不达）、|N|=0 不可除 → `needs_evidence` 并独立审「较大影响」分支（L09）。
3. **OR 缺证**（科创板资产支不达、市值缺）：整支 `needs_evidence`，不判「未达」（L05 反向：一支确真即达）。
4. **PIT**：分母必须评估时点已可得（L08 事后回填禁止）；12 个月累计线与 F23 的 10 日窗是两个量纲，不得互代。

## 对 R-01 草案的采纳说明

§1–§7 采纳为 v4 边界的研究底稿，取舍与计数边界以本裁定为准。`q5_candidate_cases.yaml` 的 18 例仅为待完善回归种子；当前 `proposed_route` 一致性仅指**金额分支与事件方向匹配、假定其余必要证据齐备后的目标路由**，不证明现有 facts 已满足完整入表条件，不构成五证门禁验收。

尤其 L03/L05：现有数值足以核其金额分支，但缺完整证据绑定；按现有 facts 执行完整路由时必须为 `needs_evidence`，不得直接当作 `risk_candidate` 正例。转成 v4 自动化回归正例前，研究员须显式补足纯合成前提：公司/并表主体与案件 ID 绑定、应诉或独立不利影响、金额原文/币种/承担份额及索赔/支持/已付/未结敞口分列、评估时点与当时已可得的最近审计分母（汇率或规则市值被使用时附来源和时点）、独立影响审查与既有命中保护。不得用标题“已核”或单个 `adverse_impact_verified=true` 代替整套证据。

正例之外，须逐项删除证据生成对应 `needs_evidence` 反例；L05 保留合法资产 OR 分支为真且市值缺失的正向金额期望，不能把未使用的市值分支缺失误判为整案缺证。原始种子保留可追溯版本，不由本裁定改写研究员 YAML。
