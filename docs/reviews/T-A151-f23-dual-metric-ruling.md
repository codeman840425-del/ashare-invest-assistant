# T-A151 裁定：F23 词表验收误报指标分列（semantic ≤5% + policy 如实报告不设上限）

日期：2026-11-10（北京时间）｜裁定人：架构师｜输入：研究员 T-R23 复核结论（PR #21）与 A2 请求
依据：plan T-R22 裁定①②（L1000）、T-R23/rules_freeze_v2_1.yaml、f23_v2_1_cases.yaml、engine_gaps_f23.md、f23_freshness_protocol.md。

## A2 问题

T-R22 裁定① 验收写「命中条目逐条人工复核（**误报率 ≤5%**）」，该裁定定义于 **v1 纯语义词表**——当时「命中但语义非风险」全部是词表错检，≤5% 度量词表语义精确度。v2.1 新增两条**政策规则**（`inquiry_transfer_policy` 询价转让一律命中且优先于整条排除、`concert_change_policy` 一致行动到期保守命中），其设计意图即保守否决：撤销/终止/不实施的询价转让也命中（冻结纪律明写「不暗加豁免」）——政策命中但语义非风险是**设计功能**，不是缺陷。若维持单一 ≤5%，政策规则大概率过不了验收，验收压力会逼实现给政策规则加豁免，等于用验收指标改写已冻结的政策语义。

## 裁定：分列双指标（选项 B）

1. **semantic 误报率 ≤5%（验收门，保留 T-R22 ① 原意）**：仅统计**语义规则**命中（controller_equity 等标题可判类）但语义非风险的比例。词表质量门槛不变。
2. **policy 命中差异：如实报告，不设上限（观察项，不作门）**：政策规则命中但语义非风险的条数与占比单独统计、写入验收报告首页；不构成失败条件。净效果由既有机制承接——simulating 期间否决率记 G6 观察项（T-R22 ②），W-01 若几乎无法买入须上报（v2.1 冻结 criteria 已含）。
3. **漏报 0 不变**：未命中抽 100 条漏 0 的验收对语义真风险一视同仁；政策规则只增命中不减命中，漏报口径不受影响。
4. **标签纪律**：semantic_truth 与 policy_hit 分列人工标注，不得以政策命中充当语义真值（v2.1 冻结 labels 原文，维持）。
5. **适用范围**：本裁定只改验收指标口径，不改 v2.1 冻结规则本体、不加豁免、不动 F23 declared 状态；F23 升 verified_doc 仍须 T-R22 ① 的 ≥1,000 条不按关键词筛的全量样本 + 本双指标通过。

## 不选另两项的理由

- 维持单一 ≤5%：政策误报是功能非缺陷，硬套会诱导违反冻结纪律的「暗加豁免」，或迫使政策规则整体回退（丢掉保守否决安全性）。
- 整体放宽不设上限：语义规则部分的词表质量失去门槛，T-R22 ① 对错检的约束被连坐取消，不可取。
