# T-A156 裁定：F23 v4 扩表边界（Q-5 七类 + 诉讼金额分流 + 异常波动 + FP-3/K-1）

日期：2026-11-11（北京时间）｜裁定人：架构师｜输入：R-01 草案（PR #41，5bc96a4+3fed15c）及其官方条款核读（S4 沪主板 §7.4.1–7.4.4、S5 科创板 §9.1.1–9.1.5/§9.4.1，附件 SHA 已登记）。
依据：T-A151 双指标、T-A152/T-A153 v3 冻结纪律、f23_lexicon_spec §3.2/§7/§9。

## 裁定 1｜能力范围：v4 维持标题链，不开结构化正文证据链

- v4 仍只消费公告标题（zt/t/nr 链现有字段）。金额、应诉身份、集团合计、市值分母等结构化证据**不进 v4 输入**——理由：当前链路无正文抽取与财务字段绑定契约，开结构化链的工程成本与 PIT 绑定风险远超标题词表的收益；「标题观察 + 人工证据记录」即可覆盖研究侧发现需求。
- 重大诉讼/仲裁标题在标题链下的处置：**不新增 policy**。`重大诉讼/重大仲裁/累计诉讼/累计仲裁/涉及诉讼/涉及仲裁` 进观察清单（observe），不贡献 F23 计数——理由：原告/被告方向、金额达线与否在标题层不可判，保守否决会把大量原告追款/小额涉诉计成风险，误报代价未被论证（T-A151 政策纪律：政策须登记理由与预计代价，本类无此论证）。

## 裁定 2｜金额与作用范围：采纳 §3 板块分流，仅作研究层判定标准

- 沪主板 `M > 1000万 AND M/abs(N) ≥ 10%`、科创板 `M > 1000万 AND (M/A ≥ 1% OR M/V ≥ 1%)` 的**严格大于、绝对值分母、OR 缺证不判未达**三点全部采纳为研究层判定标准（人工核验用），不改标题匹配器。
- `abs(N)=0` 不可除、未来分母不回填（PIT）、深市/北交所/历史版本无核读规则时 `needs_evidence` 不默认回退沪主板——采纳。
- 12 个月累计线与 F23 十日窗为两个量，不得用 10 日标题金额相加替代；同案进展不重复累加——采纳。
- 原告身份达披露线 ≠ 不利风险（L07 口径）——采纳：`observe`，除非另有已核不利影响。

## 裁定 3｜异常波动：全部 observe，不设下跌政策否决

- 普通/上涨/下跌/严重异常波动停牌核查四类一律 `observe`，不贡献 F23、不作政策否决。**不采纳**「下跌异常波动保守否决」候选：下跌与基本面恶化的因果未被论证，且交易层面风险已由可交易性模块（涨跌停/停牌）处理，词表重复计风险只会抬高 policy 误报。
- 复合标题「异常波动暨债务逾期」等：独立事件按既有类别命中（`retain_existing_hit`），观察标签不得清除已有命中——采纳草案 §4 表。

## 裁定 4｜Q-5 七类逐行处置 + FP-3 事件级中性 + K-1 同轮保护

| 观察类 | 裁定 | 边界 |
|---|---|---|
| 资产查封（300169 型） | `observe`；仅当**正文人工核验**确认自身经营资产被司法查封且仍有效，才在研究记录标 `risk_candidate` | 标题层不进词表；他方/解除/对象不清 = `needs_evidence` |
| 股份质押（300638 型） | `observe` | 强平/冻结按既有类别；普通质押不加词 |
| 计提资产减值（301510 型） | `observe`，不设统一减值比例线 | 定期常规计提不构成风险事件 |
| 重大仲裁/涉及仲裁（002528/600853 型） | `needs_evidence`（标题发现待核事项） | 同裁定 1：标题层不贡献 F23 |
| 变更会计师（688249 型） | `observe` | 辞任/非标意见另行独立审查 |
| 非控制人减持结果（603458 型） | `observe` 或 `retain_existing_hit` | 不扩大到全部股东；询价转让政策不动 |
| **FP-3 内部转让（300550 型）** | **采纳事件级中性候选**：仅同一事件三项证据齐备（内部双方+集团合计未减+无对外处置）才对 `controller_equity.direction_unknown` 标中性；仅词串匹配 = `needs_evidence` | 三反例（同标题对外减持/独立风险/询价转让政策）必须保留命中；中性候选不得扩大为标题豁免 |
| **K-1 跨主体否定** | 采纳同轮保护：否定绑定主体+事件，不跨「及/和/与」吞第二主体事件 | v3 已知缺陷本单不修，v4 匹配器实现时必须有此负例 |

## 裁定 5｜样本与升级纪律：确认草案 §7

- v4 冻结前：真值定义、词表/匹配器 hash、采样日期与随机种子预注册；样本按 T-A153 优先连续交易日全量、不按关键词筛；开发观察代码/公告不得复用为独立验收。
- 对照评估保留 v3 原口径分项，不事后改旧标签制造「召回改善」；报告分列 semantic/policy/needs_evidence/类别覆盖；T-A151 双指标沿用。
- v3 冻结与特征等级在 v4 独立验收通过前原样保留；N-01 闸门不动。

## 生效与落点

- 本裁定**生效即定义 v4 开发边界**；词表/匹配器实现、冻结与验收归研究员另领单（预注册材料以本裁定 + q5_candidate_cases.yaml 18 例为基线，可增不可改语义）。
- PR #41 描述由本裁定同步；R-01 报告的「遗留：架构师裁定」清单全部闭环。

## 不采纳项与理由汇总

| 不采纳 | 理由 |
|---|---|
| v4 开结构化正文/金额证据链 | 无契约支撑，PIT 绑定风险大，成本收益不成立 |
| 「重大诉讼」类标题 policy 保守否决 | 原告/金额不可判，误报代价未论证，违反 T-A151 政策登记纪律 |
| 下跌异常波动政策否决 | 与可交易性模块重复计险，因果未论证 |
| 减值统一比例线 | 无官方单一阈值依据，发明阈值违反不造数纪律 |
