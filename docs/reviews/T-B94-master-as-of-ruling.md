# T-B94 裁定：证券搜索 master_as_of 空 / 部分缺失快照（单内裁定，不占任务号）

日期：2026-11-08（北京时间）；裁定人：架构师；依据：plan §4.6.6、契约 §7.3 ③⑥、T-A04 报告 §1。

## 裁定
1. 全空或任一所从未成功合并：首导未完成（plan §4.6.6 部署前置），属部署前置违规而非运行时业务分支。响应 `500 INTERNAL_ERROR`，details `{issue:"security_master_bootstrap_required"}`；不伪造 master_as_of，不返回 503（§7.3 ⑥）。
2. 某所曾成功、当日整份拒收：该所沿用上次成功快照日，`master_as_of` = 三所成功日最小值，200 正常返回（§7.3 ③ 原文，日期不前进）。判据：该所在 `master_snapshots` 有无 `parse_status='ok'` 且被成功合并 run 引用的历史快照。
3. 负例归属：空快照→500 单条自检归 T-B94 交付清单（覆盖任一缺失即可，不必逐所枚举）；部署前核验 master_bootstrap 已执行归运维部署清单；测试复测只验首导完成后 200 + master_as_of 正常，不要求复现未部署态。

## 落地
- 契约 §7.3 ⑥ 补首导未完成的显式行为（同批提交）。
- 后端现行实现（三所不齐 → INTERNAL_ERROR）与裁定一致，无需改动。
