`missing_evidence_cases` 显式列出 52 个单项删除向量，分别作用于两个补证正例，产生 104 个独立反例；涵盖整组缺证、主体/案件、身份原文、金额币种/份额/支持状态、PIT时点/最近审计记录及独立影响复核。删除表示“没有该项”，不能用 `false/0` 代替。每个反例均须得到 `needs_evidence`，且保留输入的既有独立命中。
