## 0. 结论速览

1. **深市主源已落地**：深交所「简称变更」xlsx（公开，一次拉全量）→ `st_ranges_sz.py` 按股票产出 ST/*ST/退 状态区间（左闭右开）。与交接团队已核实数字**完全对齐**：2022-01-01 起简称变更 1,685 条、前或后简称含 ST 的 658 条 / 370 只；与深交所终止上市名单交集 **177 只**（issue #4 所列数字逐一复现）。
2. **沪市无等价全量源**（确认 issue 结论）：上交所官方无历史简称变更表；候选为东方财富个股「简称变更」（逐股、带日期与前后简称）与巨潮「特别处理和退市」公告类别（全市场、但生效日须读正文）。两候选均未实拉（避免大面积抓取），评估与推荐见 §4。
3. **覆盖率**：深市可由 xlsx 直接全覆盖（含退市股）；沪深合计需复测侧 manifest（`hf-1min` 数据区，不在本工作树），脚本已留 manifest join 入口，缺口如实标注（§5）。
4. **主源/备源推荐**（§6）：深市=深交所 xlsx（主）；沪市=东方财富简称变更逐股（主候选）/巨潮公告正文（备）；长期=上线后每日快照差分（security_master §5.4 既有方案，回填不了历史）。

## 2. 深市 ST 区间转换脚本（`st_ranges_sz.py`）

- **输入**：深交所简称变更 xlsx；可选终止上市列表 xlsx（用于闭合退市股末端区间）。
- **判定规则**（沿用 security_master §5.5 的确定性派生，本脚本只落地深市历史口径）：
  - 简称（NFKC 归一 + 去空白）以 `*ST` 开头 → `*ST`；否则以 `ST` 开头 → `ST`；含「退」→ `退`；其余 → 非 ST。
- **区间构建**：同股按变更日期升序，「变更后简称」决定的 flag 自该日起生效，至下一条变更日（左闭右开）；末段无后续变更时——若在终止上市名单中，用终止上市日闭合（`closed_by_delist=true`），否则 end=null（在市、状态持续）。
- **输出**：`sz_st_ranges.jsonl`（全量区间，含非 ST 段用于覆盖审计）、`sz_st_summary.json`、可选 `sz_st_ranges.csv`。
- **用法**：`python st_ranges_sz.py --xlsx <简称变更.xlsx> [--delist-xlsx <终止上市.xlsx>] --out <dir> --since 2022-01-01`（依赖 openpyxl，研究侧 `uv run --no-project --with openpyxl==3.1.5 python`）。
- **本轮实测**（xlsx 拉取日 2026-11-10）：总变更 7,503 行；2022+ 与 ST 相交区间 588 段、378 只（含退）；终止名单闭合 1,000 段末段。

### 2.1 与交接数字的对齐验证

| 指标 | issue #4 已核实 | 本脚本实测 | 对齐 |
|---|---|---|---|
| 2022+ 简称变更条数 | 1,685 | 1,685（前或后简称口径） | ✔ |
| 前或后简称含 ST 的条数 | 658 | 658 | ✔ |
| 涉及股票只数 | 370 | 370 | ✔ |
| 深市 ST∩终止上市名单交集 | 177（issue 用「退市 99 只交集」另一口径，见 §5） | 177 | ✔ |

> 两个口径并存：**统计口径**（658 条/370 只 = 任一简称含 ST 子串）用于与交接对齐；**区间口径**（588 段/378 只 = security_master §5.5 三态派生区间）用于生产。区间口径更细（*ST→ST 升级、摘帽再戴帽各自成段，且含「退」态）。

## 4. 覆盖率

### 4.1 深市（可算，已算）

- 深市 ST/*ST/退 区间覆盖股票：**378 只**（区间口径，2022-01-01 起与区间相交）；其中与终止上市名单交集 **177 只**。
- issue #4 的另一口径「与 HF manifest 深市清单交集 364 只、其中退市 99 只」——该口径依赖复测侧 manifest（见 §4.2），本侧以 xlsx 全量 + 终止名单为准，两口径差异在 manifest 的范围（HF manifest 只含复测数据区有行情的股票）。

### 4.2 沪深合计（依赖 manifest，如实标注缺口）

- 复测侧 manifest（沪深 5,387 只、退市 177 只单列）位于 HF 数据区（`hf-1min/2022plus` 等），**不在本工作树**；按红线不读外部私有样本路径、不代造清单。
- 覆盖率的机器口径已写入 `st_ranges_sz.py` 的扩展点：传入 manifest（`code` 列表）即可 join 出「深市覆盖数 / 缺失数」；沪市侧在 §3 来源未落地前**不产出区间**，如实记 0 覆盖待补。
- 本单结论：**深市可即时覆盖 378 只（含退市 177 只交集）；沪深合计覆盖率待 DS 侧在数据区跑脚本时 join manifest 后产出**，脚本已支持。
