## 2. 确定性规则（建议合入 F23 正文）
1. **只看标题 `zt`**。归一化：去 HTML、NFKC（全角转半角）、去空白、“其它”统一为“其他”。
2. **标题级排除**（命中即不计）：
   - 含 `澄清`（按裁定示例）；
   - 含 `审核问询函` / `注册环节`（再融资、重组审核，不是风险）；
   - 含 `制度`、`管理办法`、`工作细则`、`承诺函`、`专项审核报告`、`情况表`、`汇总表`、`关联资金往来`、`核查意见`、`法律意见书`、`鉴证报告`、`非本公司事项`；
   - 评级机构的“关于关注…”或“关注公告”；
   - 标题以中介机构名开头（会计师事务所、律师事务所、证券公司、资产评估机构、评级机构）。
3. **子句**：按标点和“暨 / 并 / 并且”切分；“及 / 和 / 与 / 、”并列时不切分，同一个动词（如“撤销”）统辖并列的几个宾语。
4. **否定**：关键词每出现一次单独判断。
   - 前置否定：同一子句内，在关键词之前（可与关键词重叠，如“不减持”“无保留意见”）出现该类别的否定词。
   - 后置否定：关键词之后若干字以内出现后置否定词，默认 10 字；审计类 20 字，冻结类 2 字。
   - 重置：否定词与关键词之间出现重置词（继续、仍、叠加、新增、再次）时，否定失效。例如“撤销退市风险警示并继续被实施其他风险警示”，其他风险警示仍算命中。
   - 只要有一次出现没有被否定，该类别就算命中。
5. **组合类**：控股股东减持要求标题同时含 `减持`（且这次出现没有被否定）和 `控股股东 / 实际控制人 / 实控人` 之一。**标题无法判断“大比例”**，所以 v1 对控股股东或实控人的减持一律计入（与 catalog 的“控股股东大比例减持”不同，见 §4 第 3 条）。
6. **计数**：每条公告最多计 1（命中多个类别时也只计 1，类别并列记录）。
7. **归并与聚合（保守，与输入顺序无关）**：
   - 先过滤（精确时刻 PIT，北京时间 +08:00）：**F23 不是盘中更新的特征**，每天冻结在 D 09:30。as_of < D 09:30 → null；否则只计 `available_from ≤ D 09:30` 且交易日 ∈ [D−9, D] 的记录，D 日 09:30 之后（含下午新公告）不参与。as_of 与 available_from 须为带时区 datetime，naive/纯日期抛 ValueError（不依赖调用者，不因日期相等默认可见）；任一记录 available_from 未知 → null。
   - 再归并：可见记录中，`nr`（链接）相同，或（代码，去掉“（更正后 / 修订稿 / 修订版 / 更新后 / 英文版 / 更正）”后缀的标题，可交易日）相同，任一成立即为同一实体。归并可传递，用并查集实现。
   - 最后计数：同一实体中任一记录命中即为风险（OR），每个实体最多计 1。这样避免了旧写法“先去重再匹配”的漏计问题（同一实体先出现不命中的记录、后出现命中的记录时会漏计），也避免了结果依赖输入顺序。
8. **窗口与 PIT**：窗口为**含评估日 D 在内共 10 个交易日，即 [D−9, D]**（F23 原文③）。可得时点按 plan T-R22 裁定④：对 t 与 first_seen_at 中**已知的**各自求生效时刻再取 max（不早于已知首次观测，首次观测之后的信息不回流过去）。生效时刻：交易日且时刻 < 09:30（含盘前）→ 当日 09:30；其余（含恰为 09:30、盘中、午休、11:30/15:00 边界、盘后、非交易日）→ 次一交易日 09:30；只有日期 → 次一交易日 09:30（F23 原文“只有日期 → 次一交易日开盘”）。两者都未知才为 null。**只知 t**（`available_from_detail` 返回 `t_only_pit_limited`）只是按披露时间推断，不等于已保存的首次观测快照，回测有 PIT 局限。上一轮的午休 13:00 和 gap 返回 null 均已按裁定撤销。数据源缺失或过期 → null（不是 0）。
9. **版本**：词表变化时 `event_definitions.version_no` 和 `feature_set_version` 递增；旧版本不可变。
