## 3. v2 新增（语义与动机）
1. **regulatory_action +3 词：`行政监管措施`、`监管措施决定书`、`监督管理措施`**。动机：证监局“关于收到行政监管措施决定书的公告”是常见监管处罚类标题，v1 只认“警示函/责令改正”等具体措施名，标题只写“行政监管措施决定书”时会漏。否定沿 v1（前置 撤销/解除/不存在；无后置否定，“…已撤销”这类写法仍是 v1 已知局限）。
2. **新类别 control_instability：`变更为无实际控制人`、`变更为无控股股东`、`控制权存在不确定性`、`控制权不稳定`**。动机：控制权由明确变为无或不确定。**“解除一致行动”本身不计**（真实反例：炬光科技、燕东微、航天南湖均明示控制权不变）。否定：前置 不存在/不会/未。
3. **新类别 controller_equity（控股股东/实控人持股下降）**，判定顺序：
   - 主体：标题须含 控股股东/实际控制人/实控人（去掉“非控股股东/非实际控制人”后）；无主体但有“询价转让” → 不计，标 `subject_unknown`。
   - 明确下降：任一子句含 减持/减少/下降/降至/降低/询价转让/变卖 且未被前置否定（不减持、未减持、终止、取消、未实施、不会）→ 计入。询价转让对出让方必为减持，主体为控制人即计。
   - 明确上升：含 增持/增加/上升/提高/受让/认购/被动增加 → 不计（反例）。
   - 只有“权益变动/持股比例变动/股份变动/持股变动”而无方向：含 被动稀释、一致行动协议/关系、表决权、继承、分割、赠与、划转 → 不计（结构性/非交易变动）；否则**保守计入，标 `direction_unknown`**。
   - **不把任何“权益变动”都判风险**：无控制人主体、上升、中性、否定均不计，各有反例。
   - v1 的 `controller_selldown`（减持 + 控制人）原样保留，可与本类同时命中，每条公告仍只计 1。
4. 有意的行为变化（v1 回归 153 例中仅 1 处）：天力锂能“控股股东…股份被司法变卖完成过户并解除质押、解除司法再冻结暨权益变动”v1 判否，v2 判是（司法变卖属被动减持）。
