# F23 引擎缺口（T-R23 独立缺口文档；不并入 T-R16 总表、不占其编号）

编排者 2026-11-07 裁定：F23 采用保守否决，标题级确定性规则；正文/主体识别等新数据链 MVP 后再做。以下缺口均不写手工证券白名单。

| 编号 | 缺口 | 当前处理（v2.1） | MVP 后方向 |
|---|---|---|---|
| F23-G1 | 询价转让出让方是否为控制人，标题常只写“股东” | 政策：标题含“询价转让”一律命中（含普通股东、撤销/终止/不实施、中介文件、澄清），**优先于整条排除，无否定豁免** | 读正文“出让方是否为控股股东、实际控制人”段落判主体与是否实施 |
| F23-G2 | “控制人/一致行动 + 协议到期/解除/终止 + 权益变动”是否含减持 | 政策：保守命中；可能只是不再合并计算，非事实判断 | 读正文权益变动表“减持股数/变动方式” |
| F23-G3 | 控制人“权益变动”无方向词 | 保守命中，标 direction_unknown | 读正文“变动方向：上升/下降” |
| F23-G4 | 后置否定（如“…决定书已撤销”）在监管类不生效 | 沿 v1，按命中处理 | 扩后置否定窗口并补反例 |
| F23-G5 | “澄清”整条排除、中介机构名单不全（v1 已裁定 gap） | 保持；仅询价转让政策可越过 | v2 之后细化 |
| F23-G6 | 同一事件多公告在 10 日窗内重复计数 | 按 nr 与次键归并；不同标题的同一事件仍各计 1（N-01 只看 >0，不影响否决） | 事件级归并 |
| F23-G7 | 否决率 / W-01 可买性 | 未测；样本公告命中率**不能**替代策略否决率或真实机会缺口 | simulating 期间按股票×交易日统计 F23>0 的比例（G6 观察项）；若 W-01 几乎无法买入须上报 |

预计误报类型（政策命中但语义非风险）：非控制人（私募/VC/员工平台）询价转让；撤销、终止或不实施的询价转让；券商核查报告、律师意见等中介文件及澄清公告中的询价转让；一致行动关系到期或解除但无股份减少；控制人无方向“权益变动”实为被动稀释以外的非减持变动。误报率在验收中如实统计，**不设上限、不因政策命中改写语义标签**。
