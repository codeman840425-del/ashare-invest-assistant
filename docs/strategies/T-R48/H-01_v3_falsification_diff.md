## 2. 公共口径（F1–F3 共用）

### 2.1 事件与周期
- 事件：H-01 系统实例对持有证券求值，某规则组（exit = X1/X2；W1；W2；W3）在日 T 由「非真」（False 或 null）变为 True 的**首日**；单位（账户, 证券, 规则组, T）。只用 T 日盘后求值结果（card:15-16）。
- 周期 h：按 RC5 口径 B 映射 intraday_t→1、short→5、swing/long→20（P2N-R10/README.md:82；T-R35/README.md:68-69、:88-90）；周期取该观测所属建议的 horizon，缺失再取明确版本周期；H-01 为四周期卡、无单一版本周期，**仍不清楚 → 跳过并记 gap `sim_fail_horizon_unknown`，不进 n、不默认 5**（T-R35 B2）。各 h 分开检验，h ∈ {1, 5, 20}（与 validation 块 horizon_days :128 一致；swing/long 共用 20）。
- 窗口只在 T+h 收盘后关闭才计入（validation.md:190 第 1 条「只用已关闭窗口」）。

### 2.2 收益（只用当时可得数据）
- `R_i(T,h) = C^{(T+h)}_i(T+h) / C^{(T+h)}_i(T) − 1`，`C^{(a)}(d)` 为 as_of=a 当次快照中 d 日的 `f.close_qfq`（qfq@a，card:15 `x_qfq(d)=x(d)×A(d)/A(T)`）。同一快照内取比值，除权已抵消；h ≤ 20 < 预热 62 根（card:16），快照必含 T 日。T+h 前不读任何 T 之后的数据定义事件。
- 参考价：**主口径 T 日收盘 → T+h 收盘**（只用已登记键）。与 validation.md:38「盘后信号 T+1 开盘成交」不同：缺开盘价键，隔夜跳空无论持有或卖出都要承担（validation.md §7.1A 设计要求 3），故此偏差对「持有 vs 离场」比较是共同项；待开盘价键登记后改 T+1 开盘（§6 P-5）。
- 停牌：T+h 停牌则用 (T, T+h] 内最后一个有效 K 的收盘（停牌期间不变价，伪停牌行按缺失，validation.md:31）；T+1 `f.is_suspended=true` 或 `f.limit_locked_down=true`（卖出不可成交）→ **剔除出 n，单独计数报告**（validation.md:39）。
- 现金收益记 0（无已登记的无风险利率键）。

### 2.3 「超额」基准（T-A111 ②）
- 基准 = **当日等权池**：`P_T` = 系统在 T 日已取数并可求值的全部持有证券（各账户持仓去重，即 H-01 实际求值范围，card:74-77），剔除事件证券自身及 T 日停牌者。`R_pool(T,h) = mean_{j∈P_T} R_j(T,h)`，`AR_i = R_i − R_pool`。
- `|P_T| < 5` → `AR_i = null`，记 gap `bench_pool_insufficient`，不进 n（门槛 5 借 feature_spec.md:86「组内 N<5 → null【建议】」，§6 P-4）。
- 池在 T 日定成员，不因 T 后退市/停牌剔除（防幸存者偏差，validation.md:29）。
- 不用沪深300：validation.md:201 默认基准为沪深300，但其收盘未登记为键；改用沪深300 须先登记该键 → **阻塞：需编排者裁定**（§6 P-4），在裁定前一律用等权池。

### 2.4 去重与重叠样本
- 主检验用**不重叠抽样**：同（证券, 规则组, h）内，上一计入事件的窗口 (T, T+h] 未结束前的新事件不计入（比 validation.md:131 默认 3 日冷却更严；h=1 时等价）。同证券在多账户同日触发，收益类检验按（证券, T）去重。
- 稳健性（只报告，不作判据）：按信号日 T 聚合为日均序列，用 Newey-West HAC t 值，滞后 = h−1（validation.md:53）。

### 2.5 样本量与多重检验
- 最小 n：每个（条件, h）不重叠、可成交、非 gap 的事件 **n ≥ 30** 才判定（card:130 `min_n: 30`；validation.md:44）；5 ≤ n < 30 只报 `small_sample`，不判证伪；n < 5 不显示。
- 「显著高于」类条件（F1 各 h）组成一族，p 值用 **Benjamini–Hochberg，q = 0.10**（validation.md:147 建议）；同时报告 Holm（FWER 0.05）结果作敏感性。
- 「无区分度」类条件（F2、F3 各 h）判据是「点估计不支持 + 检验不能拒绝」，多重校正只会让证伪更容易触发，故**不做校正**，单个检验单侧 α=0.05，并报告 α=0.10 敏感性。

### 2.6 触发后的处置
- 任一条件满足 → **通知管理员复审，不自动退役**（validation.md:193 第 4 条）。simulating 期间可选：参数或口径修订出新版本（重走 G1–G7），或管理员按契约「任意→retired」退役；`observing` 不能从 simulating 手动设置（T-R35/README.md:84）。published 后的健康度另按 validation.md §6.2 状态机，不因本条自动改状态。
- 报告按大盘状态（`f.market_regime_idx`）、板块分组（validation.md:130），只作展示。

## 3. F1：离场后继续持有是否显著更好（替换 v2 card:42，T-A111 ①）

- 事件：exit 组（X2 为主；X1 同算，见 §4.3）首日。
- 统计量：`D_i = R_i(T,h)`（继续持有 vs 离场转现金；两者窗末都须卖出，卖出成本一阶相互抵消，故用未扣费 R，另用效应门槛体现成本）。
- 检验：H0 `median(D) ≤ 0`，H1 `median(D) > 0`，**单侧精确符号检验**（validation.md:105；与卡面「中位数」一致，不假设对称）。
- 证伪（全部满足）：n ≥ 30；BH 校正后 q ≤ 0.10；且 `median(D) ≥ δ`，δ = 该批事件按卡面成本参数（card:82-88，含最低佣金 5 元与冲击分档，按 validation.md:40 示例账户规模）算出的**往返成本中位数**（倍数 k=1，§6 P-3）。
- 阈值算术（不是结果）：n=30 时单侧 p ≤ 0.10 与 ≤ 0.05 都要求 D>0 的个数 ≥ 20（p=0.0494）；p ≤ 0.01 要求 ≥ 22；n=50 时 p ≤ 0.10/0.05/0.01 分别要求 ≥ 31/32/34；n=100 时分别要求 ≥ 57/59/63。F1 族共 3 个检验（h=1/5/20）：BH 下若只有一个检验显著，其 p 须 ≤ 0.10/3≈0.033，n=30 时即 D>0 个数 ≥ 21（p=0.0214）；Holm 0.05 下最小 p 须 ≤ 0.0167，n=30 时 ≥ 22（p=0.0081）。

## 4. 集中度主张（T-A111 ③）与 W1

### 4.1 方案 B（推荐）：改写 why，集中度作风险限额
- why 改为：「跌破成本缓冲、跌破长期均线是可检验的持仓风险上升提示；单只/行业集中度超限是**风险限额提示**（阈值属 estimate），不作可检验的预测机制；只给出风险方向，不预测收益」。与 epistemic card:72-73 `single_cap`/`sector_cap: estimate` 一致；W2/W3 规则（spec card:109-110）不变。
- 理由：W3 的证伪必须用行业归属，而 `f.sw_l1` 未 verified（§1）；方案 B 不新增数据需求，并满足 T-A111 ③ 的第二种选项。

### 4.2 方案 A（备选）：保留集中度主张，补可量化证伪
- **F3-W2**（单只集中度）：事件 = W2 首日（`ctx.position_weight > p.single_cap`，T 日盘后）。反事实组合：把超出部分 `e_i = w_i − single_cap` 转现金，`r_cap = r_act − e_i × R_i(T,h)`；`r_act` 为账户持仓按 T 日权重的 h 日收益（各持仓 `R_j` 同 §2.2）。指标：下行半偏差 `DD(x) = sqrt(mean(min(x,0)^2))`，`Δ = DD(r_act) − DD(r_cap)`（主张为 Δ > 0）。检验：配对 bootstrap（B=2000，固定种子，确定性），单侧 H1 Δ > 0。证伪：n ≥ 30（按账户×T 不重叠）且 `Δ ≤ 0` 且 bootstrap 单侧 p > 0.05。边界：`ctx.position_weight` null → 不计入并记 gap；任何持仓 R 为 null 则该账户事件剔除；单持仓账户（w=1）照算。
- **F3-W3**（行业集中度）：同 F3-W2，把 `w_i` 换成 `ctx.sector_weight`、`R_i` 换成该行业内持仓按权重的组合收益。**阻塞：需编排者裁定**——行业归属依赖 `f.sw_l1`（declared，无历史成分），不在已登记 verified 键内；可选：(a) 裁定允许复用 W3 规则本身已用的同一归属来源（不新增需求）；(b) 不补 F3-W3 而对 W3 采用方案 B。「未分类」持仓（card:9 W3 为 null）不计入。
- 敏感性：bootstrap 种子与 B 只影响 p 的第 3 位小数级；`single_cap` 默认 0.20、`sector_cap` 0.40 为 estimate，按 spec card:103-104 一步（±0.05）复算 Δ 符号是否翻转并报告。

### 4.3 X1（可选附注，不进 falsified_by）
T-A111：X1 是计划绑定止损（card:8/:54/:106），不在 why 中，不必单列。仅建议在 F1 报告里把 X1 子集单列 `median(D)` 与 n，供用户复看计划止损距离；结论不触发 H-01 证伪（X1 无 H-01 参数）。边界：窗口内计划止损被修改 → 用 T 日生效的止损；未绑定计划时 X1 不求值（card:8）。

### 4.4 F2：W1 转弱无区分度（替换 v2 card:43，T-A111 ②）
- 事件：W1 首日（默认 ma_long=60、ma_break_days=3，spec card:99-100）。统计量：`AR_i(T,h)`（§2.3 等权池）。主张：W1 后超额偏负，即 `π = P(AR<0) > 0.5`。
- 证伪（全部满足）：n ≥ 30；`median(AR) ≥ 0`；且单侧符号检验 H1 `π > 0.5` 的 p > 0.05（数据不能显示负向区分度）。
- 敏感性：按 spec card:99-100 一步（ma_long ±5、ma_break_days ±1）复算 median(AR) 符号，邻域内符号翻转则在报告中标「不稳健」（validation.md:142）。
