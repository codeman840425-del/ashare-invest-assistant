每个股票日都**同时**命中「上市状态不明」与「ST 状态不明」，`day_kinds` 判 `EXCLUDED`（`data.py:392–397`、`:415`）；模拟循环遇到 `EXCLUDED` 直接跳过该日（`sim.py:447`）——**特征/信号/入场条件从未被求值**，所以不存在「策略无信号」。

### 3.2 输入侧证据（三项均缺）

- `summary.data.st_coverage = null`、`listing_coverage = null`、`termination_list_sha256 = null`。
- 代码路径：`runner.py` 的 `--st-history` / `--listing-history` / `--delisting-list` 均为**可选参数**；未给时 `data.load_status_history(None, kind)` 返回 `({}, None)`（`data.py:305–306`）→ 每日 `st_status/listing_status = None` → 判「不明」剔除。
- 方案早有预期：§2.1「ST/*ST 历史：**数据源待定**（HF 与 tdx-pack 都没有；`securities.risk_flag` 是当前值，用它就是前视）」；§2.6 D1「数据源待定……在此之前按 §2.3 剔除状态不明的股票-日」；§2.3「**ST 来源未定时的后果**：……主跑会因裁定 ③ 剔除大部分样本，P1 很可能不满足，结论只能是 §8.4 的 ③『数据不满足』……等 T-DATA-SRC 的 ST 调研结果再重跑；**不得改用当前 ST 状态代替**」。
- 上市状态历史同样缺失：`listing_status_unknown` 也等于 100%。**即使补上 ST、只要上市状态历史仍缺，仍会 100% 剔除**——两条输入都必须补。
- 终止名单缺失：`delisting.state=unknown`、`reason="exchange termination list missing or empty"`（P9 因此 unknown）。
- 本机只读扫描（`data/`、`F:\workspace\team`、DS 侧）未检出任何 ST/上市状态/终止名单 CSV 输入；即这次不是「有文件未传」，而是**输入产物尚不存在**。

### 3.3 样本容量并不小（反证「策略无信号」）

忽略状态输入、从 2023-04-10 起算，潜在可评估股票日 ≈ **470.7 万**（2023 剩 969,643 + 2024 1,310,914 + 2025 1,316,331 + 2026 1,110,485）；再扣停牌/新股/日线锚缺失，保守下界仍 ≈ **441 万**。按框架触发率 0.1%–5%，应产生数千至数万腿；实际 0 腿只能由「全部股票日在状态门禁被整日剔除」解释。

### 3.4 其他输入侧观察（记录，不影响本次归因）

- `vipdoc_single.mode=shared_date_use`、`vipdoc_main.independent_package_equality=not_applicable`：两套 vipdoc 用同一只读快照的共享日期，独立双包等价性未核验（拼接门禁 `L14` 仍通过）。属输入侧限制，复跑前若要求独立双包，应补齐。
- `L11.snapshot_revisions=unable_to_verify`、`bar_quality={outside_dates:0, missing_bars:110,127,600, bar_ok_failed:4,074,747}`：均为方案允许的报告项，非本次空结果原因。

- 不得据此：改 34 组网格、调 k/floor/d、宣称策略无效、或宣称成本/统计实现正确。
