### 2.1 T-R63/T-R63b/T-R63c 返修（RV-20 系列；只改匹配器作用域与坐标，词表未改）

- **他方事件「等长屏蔽」（T-R63b/T-R63c P1）**：`exclude_all_of` 只在对象判定为他方时，把「动作词→事件词」这段用**等长屏蔽标记**替换（不删字符、不拼接）——关键词匹配与否定窗口都在**原始坐标**上进行（「已解决」等后置否定不会因抹除缩短间距漂移进窗口），同子句自身风险词（如债务逾期）仍参与匹配；自身称谓（本公司/我公司/公司自身/公司本身/发行人/本公司及关联主体/及其子公司/及其控股子公司）不屏蔽；**对象不明的中间态一律不屏蔽**（保守，宁误报不漏报）。
- **渠道否定整段标记 + 绑定最近减持事件（T-R63b/T-R63c P2）**：从「不通过/未通过/不会通过」起点向右整段标否定——嵌套渠道词（「集中竞价交易」里的「竞价交易」）随整段幂等，回看到**子句边界**、不按 16 字；渠道肯定/否定**绑定最近减持事件**（作用域=该减持动词的修饰段），否定与关键词之间出现其他事件词（增持）时否定属于更早事件、不适用本次。反例「控股股东不通过集中竞价而**通过大宗交易减持**」→ 命中；「通过大宗交易**增持**而不通过集中竞价减持」「不通过集中竞价交易减持」「不通过四渠道并列减持」→ 不命中；「不通过集中竞价**增持而减持**」→ 命中。
- **check 断言（T-R63b P3）**：递归展平保留**空映射节点**进差异集合，「一有一无」不再漏判。
- **回归**：V3-P11–P19、V3-N11–N15，**34 例全绿**；B 轮归档对照仍 **18→16**（removed 恰为 300892/300598、added 0）；v3 新样本 1,367 条前后对照 **29→29 零变化**（验收数字不变）。
