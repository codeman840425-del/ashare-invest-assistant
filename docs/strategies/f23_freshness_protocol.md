## 4. 新鲜度：分子分母定义（什么算「应取到」）

- **真值（分母来源）**：巨潮公开页该股 d 日公告清单，按 `cninfo_announcement_id` 去重（更正公告是独立 ID，各算一条）。D1–D5 合并的真值条数为分母 **N**。
- **「应取到」**：该公告在 T-B86 于 d+1 北京 08:20（09:00 前有效）的取数结果中能匹配到。匹配规则（确定性，按序）：
  1. **ID 匹配**：`nr` 链接含真值 `cninfo_announcement_id`（如 `1225650594`）；
  2. **标题全等**：归一化标题（冻结匹配器 `norm()`，NFKC+去空白+去 HTML+全半角映射）与同股同日条目全等；
  3. **前缀唯一**：归一化标题互相为前缀且 ≥12 字，且该股该日仅一条候选（歧义 → 不算命中，标 `ambiguous` 列人工复核）。
- **分子 M**：分母中被上述规则命中的条数。
- **命中率 = M/N ≥ 95%**（5 天合并计算，不按天放行）；每日明细照记。
- **边界处理**：
  - 某股当日取数 `fetch_ok=false` 或响应异常 → 该股当日真值公告全部计 miss（另记 `fetch_fail`，一次失败污染多少算多少，不豁免）；
  - 某股当日真值公告为 0 条 → 该股当日**不产生观测**（不进分母），台账记 `gt_n=0`；无公告比例高时如实报架构师（观测数不足 100 的影响由架构师裁）；
  - 09:00 前未取到、之后才出现 → 该条 miss，另标 `late`（新鲜度失败的典型形态）；
  - T-B86 当日无证据（接线/授权中断）→ 当日记 `no_evidence`，不虚构，不计入分母；连续发生即报编排者。
- **辅助指标**（同记不作为主判据）：股票-日网格 20×5 的「取数成功率」与「全命中日占比」。主判据采用**公告条数口径**（对「命中率」最直读的落法）；plan 未写明条目级/天级，此点随结论一并请架构师确认。
- **不达标处置**：如实报告，F23 保持 `declared`；不重试、不追加取数（预算上限 T-A19 全批 128 次已含本项 100 次）。
