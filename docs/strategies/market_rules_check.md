## 1. 结论

**属实。** 上交所、深交所均于 **2026-04-24** 发布 2026 年修订版交易规则，**2026-07-06 起施行**，把**主板风险警示股票**（ST、*ST）的价格涨跌幅限制比例**由 5% 调整为 10%**，与主板其他股票一致。证监会上海监管局的发布文章给出了同样的说明。三处出处都是官方网站（sse.com.cn、szse.cn、csrc.gov.cn），不是新闻转载。

| 项 | 核实结果 |
|---|---|
| 变化 | 沪深主板风险警示股票涨跌幅 5% → 10% |
| 发布日 | 2026-04-24（沪、深同日） |
| 生效日 | 2026-07-06 |
| 适用范围 | 上交所主板、深交所主板的风险警示股票（ST、*ST） |
| 不变 | 创业板、科创板（含风险警示股票）本就 20%；北交所（含风险警示股票）30%，不在本次调整范围（证监会上海局文） |
| 建议 | plan 第 2168 行与第 1107 行、第 2646 行的"【待 T003 补测核实】"可改为"已核实（出处见 docs/strategies/market_rules_check.md）"——**需架构师修改**（研究员无权改 plan） |
