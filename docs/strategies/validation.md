## 1. 共同前提（A、B 两线都必须满足）

### 1.1 按时点（point-in-time）
- 每个特征带 `available_at`（`_template.md` §7.2）；在时点 t 只用 `available_at ≤ t` 的数据。
- 财报按披露日 `plrq` 对齐（文档已列·待T003验证）；`plrq` 缺失的报告期不使用；若麦蕊只保留修订后版本，在报告中注明"可能有轻度前视"。
- 公告：麦蕊盘后更新（T003），**一律视为次一交易日 09:30 起可用**。这比 plan §2.12.2"交易时段内发布 → 下一根 1 分钟 bar"更保守，因为麦蕊数据在盘中拿不到（见 §10 差异 3）。
- 龙虎榜约 20:00 发布 → 次一交易日；业绩预告时刻精度未知 → 按盘后。
- 因子：麦蕊回溯历史因子是否按当时可知信息计算未核实 → 核实前只用本项目按时点落库的截面（`first_seen_at`），或用"日线 + 报表 `plrq`"本地重算。
- 指数/行业成分：用当时成分。麦蕊成分周更、无历史成分 → 从落库开始积累周快照；在此之前，涉及行业中性化或行业轮动的检验只能注明"使用当前成分，存在前视"，**不得作为晋级依据**。

### 1.2 样本与幸存者偏差
- 样本必须包含已退市、已摘牌、曾 ST 的股票（日线回溯到上市日，T003 已实测；退市股能否取到**待T003验证**）。若取不到退市股，报告中必须注明"幸存者偏差未消除"，结论降级为"仅供参考"。
- 排除（不进入截面排名）：停牌、ST/*ST、退市整理、上市 < 60 个交易日（plan §2.12.1）；规则型策略按卡内 universe 处理。
- 伪停牌占位行（T003：`sf=1, v=0`、OHLC 相等）按缺失处理，不当作停牌、也不当作零收益日。

### 1.3 复权与收益口径
- 指标用前复权，收益用后复权（或总收益）；分钟线只有不复权，跨除权日截断。
- 前复权序列每次除权后整段重算：研究侧要用"当时的前复权序列"（或用后复权计算指标，结果等价于比例不变的指标，但均线价位不同），并在报告里写明采用哪种。

### 1.4 成交与成本（与 `_template.md` §18 同一公式）
- 入场：盘后信号 T+1 开盘价；盘中信号下一根 1 分钟 bar 开盘价（plan §2.8.1）。出场同理。
- 不可成交：一字涨停买入、一字跌停卖出、停牌 → 记"不可成交"，不计胜率，但计数单独报告。**不可成交比例本身是一个必须报告的指标**（打板类策略的偏差主要来自这里）。
- 成本：佣金（用户费率或默认，最低 5 元）+ 过户费 + 卖出印花税 + 基础滑点 + **冲击成本分档**（参与率 = 拟成交额 / 近 20 个有效交易日平均成交额；分档 0/5/15/30/60 bp，示例，待校准；ADV 为 0 或有效天数 < 5 按最高档；涨跌停不可成交不计成本）。研究侧统一用"示例账户规模"计算拟成交额（如每笔 5 万元，示例），并做 1 万/20 万两档敏感性。
- 所有交易约束取自 `market_rules` 当时版本（plan §2.13）。

### 1.5 统计结构
所有指标按 `{value, n, window, small_sample}` 输出：n < 20 标"样本少"，n < 5 不显示数值（plan §2.12.3）；plan §2.8 另有"n < 30 标样本不足"，两个阈值并存时以更严者展示（§10 差异 5）。

## 2. 因子类策略（L-01/02/03/04、W-03、S-03 的情绪因子等）

### 2.1 IC 与 RankIC
- 每个调仓日 t：截面因子值 `x_i,t`（中性化后，见 §2.4），未来 h 日收益 `r_i,t→t+h`（后复权，从 t+1 开盘到 t+1+h 开盘，与成交口径一致）。
- `IC_t = Pearson(x_·t, r_·t)`；`RankIC_t = Spearman(x_·t, r_·t)`。h ∈ {1, 5, 20}。
- 汇总：均值、标准差、`IR = mean(IC)/std(IC)`、IC > 0 占比；t 值用 Newey-West 调整（滞后 = h − 1，因为 h > 1 时相邻样本重叠），或只用不重叠样本（每 h 日取一次）。
- 截面样本数 < 100 的日子不计入（建议初值）。

### 2.2 分组
- 每期按因子分 5 组（等权），报告各组平均未来 h 日收益（扣费）、多空（第 5 组 − 第 1 组）、**单调性**（组号与收益的 Spearman）。A 股做空受限，多空只是检验工具；产品语义只用"多头组 vs 基准"。

### 2.3 换手与衰减
- 换手：相邻两期第 5 组成分的变化比例；结合 §1.4 成本算扣费后收益。
- 衰减：h = 1/5/10/20/60 日的 IC 曲线，估算半衰期；用于决定再平衡频率（月度是否足够）。

### 2.4 行业与市值中性化
- `x_i = a + Σ_k b_k·行业哑变量_ik + c·ln(流通市值_i) + ε_i`，取残差 ε 作为中性化因子（申万一级，当时成分，见 §1.1）。中性化前后都报告。
- 若中性化后 IC 大幅消失，说明因子主要是行业/市值暴露，卡片上要如实写明（如"小盘暴露"）。

### 2.5 滚动样本外
- 按时间切成 K = 5 折（plan §2.12.4），每折之间留出 embargo = 持有期 h；参数只在训练折上选，在下一折评估（walk-forward）。另外保留**最近 12 个月为最终保留集**，全程不参与任何选择，只在晋级前看一次（建议）。
- 报告每折结果与 `robustness = 0.6 × 各折中位数 + 0.4 × 最差一折`（plan）。

### 2.6 去冗余
- 同卡内因子两两 |Spearman ρ| > 0.8 提示合并（plan）；新因子对已有因子回归后的残差 IC 仍显著才算"新增信息"。

### 2.7 准入建议初值（**建议，需拍板**）
| 指标 | 建议初值 |
|---|---|
| 中性化后 RankIC 均值（h = 20） | \|值\| ≥ 0.02，且方向与 `hypothesis` 一致 |
| RankIC IR | ≥ 0.3 |
| 滚动折一致性 | ≥ 4/5 折同号 |
| 第 5 组扣费超额 | > 0，且分组大致单调 |
| 最终保留集 | 同号 |

## 3. 事件类策略（N-01、N-02、W-05、S-05、T-03 盘后部分等）

### 3.1 事件定义与 t0
- 事件用 `event_definitions` 精确定义并版本化（来源、标题关键词正则、方向、严重级别、去重窗口；plan §2.12.2）。
- **t0 = 最早可交易时刻**：按 §1.1（麦蕊公告与龙虎榜一律次一交易日开盘）。入场价 = t0 开盘价；不得用公告当日收盘价。
- 同一证券在去重窗口（如 20 个交易日，建议）内重复的同类事件只保留第一次。

### 3.2 异常收益
- 市场调整模型：`AR_i,d = r_i,d − r_m,d`，基准 m = 沪深300（plan 默认）或所属行业指数；稳健性另用中证全指。
- （可选）市场模型：用 [−250, −30] 估计 α、β，`AR = r − (α + β·r_m)`；估计窗口内有效交易日 < 120 的样本不用。
- `CAR[a,b] = Σ AR`；另报告 `BHAR`（买入持有超额，20 日窗口更接近真实持有）。

### 3.3 窗口
| 窗口 | 用途 |
|---|---|
| [−5, −1] | 提前反应/拥挤检查 |
| [0] | t0 当天（开盘入场至收盘） |
| [+1, +5]、[+1, +20] | 主要检验窗口（对应 T+5、T+20） |

### 3.4 显著性
- 截面 t 检验（均值）、Wilcoxon 符号秩或符号检验（中位数/胜率）、Bootstrap 置信区间。
- 事件在时间上聚集（如财报季、同日大量预告）时，截面相关会夸大 t 值 → 用**日历时间组合**（每天把当日处于窗口内的事件股等权组合，对基准回归求 α）作为稳健性检验。
- n < 30 只报告描述统计，不下结论（建议）。

### 3.5 拥挤检查
- `CAR[−5,−1] > +8%`（plan 默认）的事件打 `crowding` 标记；分组报告"拥挤/非拥挤"的后续 CAR。产品中拥挤标记作为反证展示。

### 3.6 准入建议初值
CAR[+1,+20]（扣费）均值与中位数同号且与假设方向一致；非拥挤组 t ≥ 2；日历时间组合 α 同号；n ≥ 30。

## 4. 规则类策略（W-01、W-02、S-01、S-02、S-04、T-01/02、H-01 等）

### 4.1 信号统计（G6 只做这一部分，不算收益）
| 指标 | 定义 | G6 用法（plan） |
|---|---|---|
| 触发率 | 触发的股票-日 / 可评估的股票-日（最近 120 个交易日） | > 30% 或 = 0 → 警告 |
| 数据覆盖率 | 必需特征非缺失的股票-日占比 | 报告；< 90% 时 `gates_missing` 可能出现 G2（系统判断） |
| 重复度 | 与已有模板命中集合的 Jaccard | > 0.9 视为重复 |
| 分布 | 触发按日期、行业、市值、板块的分布 | 发现"只在某一天集中触发"等异常 |

### 4.2 研究侧结果统计（B 线）
- 每个信号按 §1.4 成交：入场、按卡的退出规则（止损、跌破均线、时间止损）出场；同时报告固定持有 1/5/20 日的结果（与产品模拟跟踪口径对齐）。
- 指标：命中率（扣费收益 > 0）、**盈亏比**（平均盈利 / 平均亏损，扣费）、每笔扣费期望 = 命中率 × 平均盈利 − (1 − 命中率) × 平均亏损、超额（对基准）、MAE/MFE（持有期内最大不利/有利波动，用于检验止损距离是否合理）、平均持有天数、最大连续亏损、不可成交比例。
- 分组报告：按大盘环境（uptrend/range/downtrend）、板块（主板/创业板/科创板）、年份。
- 同模板同证券按冷却期去重（plan 默认 3 日），避免重叠样本夸大 n。

### 4.3 准入建议初值
扣费期望 > 0，且 > 2 × 平均往返成本；n ≥ 30；在至少 2 种大盘环境中期望不为显著负；最终保留集同号。做T 类另要求"未回补被时间止损"的比例 ≤ 30%（建议）。

## 5. 防过拟合

### 5.1 参数稳健
- 只在 `params_schema` 的 `min/max/step` 网格内搜索，**组合数 ≤ 50**（plan）。
- 报告"参数平原"：最优参数邻域（每个参数 ±1 步）的结果；邻域内结果符号翻转或下降超过一半 → 判为不稳健，默认参数取邻域中位表现最好的点，而不是单点最优。
- 默认参数尽量取文献/常用值（如 MA20/60、RSI14），并记录"是否经过搜索"。

### 5.2 多重检验校正
- 记录**每次试验**（因子、参数组合、窗口、样本切分）到试验日志，包括失败的。
- 同一批检验的 p 值用 Holm（控制族错误率）或 Benjamini–Hochberg（FDR，q = 0.10，建议）校正；报告校正前后结果。
- 可选：对规则型策略计算 Deflated Sharpe Ratio（考虑试验次数），只作参考。

### 5.3 样本内外
- 训练/验证用 §2.5 的 K 折，**最终保留集**（最近 12 个月）只看一次；看过之后再修改策略，必须换新的保留集（或明确标注"保留集已被污染"）。

### 5.4 前视与偏差检查清单（每次检验必须逐项勾选并存档）
| # | 检查项 | 怎么查 |
|---|---|---|
| 1 | 财报用 `plrq` 而非报告期 | 抽查 10 个样本的取数日期 ≥ 披露日 + 1 |
| 2 | 公告、龙虎榜、业绩预告按次一交易日 | 检查 t0 |
| 3 | 不用 T 日收盘价成交日线信号 | 检查成交价 = T+1 开盘 |
| 4 | 前复权序列用"当时版本"或已说明 | 检查复权因子版本 |
| 5 | 成分股用当时成分 | 检查成分快照日期 |
| 6 | 包含退市股 | 统计样本中退市股数量 |
| 7 | 因子截面按时点 | 检查 `first_seen_at` 或重算来源 |
| 8 | 一字板/停牌不可成交 | 统计不可成交数量 |
| 9 | 涨跌停价按当时规则版本 | 检查 `market_rule_version` |
| 10 | 伪停牌行已处理 | 统计被剔除的行数 |
| 11 | 指标预热期不足的样本已剔除 | 检查 `warmup_bars` |
| 12 | 盘中规则只用已完成的 bar；未使用日频因子做盘中触发 | 代码审查 |
| 13 | 参数选择没有用到保留集 | 试验日志 |
| 14 | 成本含最低佣金与冲击成本分档 | 检查成本明细 |

## 6. 健康度三态（A 线；沿用 plan §2.8.2，补充确定性细则）

### 6.1 三态与 plan 状态的对应
| 用户看到 | 系统状态 | 进入条件 |
|---|---|---|
| 健康 | `published` | 发布时；或从"观察"恢复 |
| 观察中 | `observing` | 见 6.2 |
| 已退役 | `retired` | **只能由管理员确认**并写审计；系统只发"建议复审/退役"提示 |

### 6.2 确定性阈值（plan 默认值，可配置）
- 权重：`w̃ = (wins + 10×0.5)/(n + 10)`，`e = tanh(avg_excess_pct / 5)`，`raw = 1 + 0.6×(w̃ − 0.5)×2 + 0.4×e`，`weight = clamp(raw, 0.3, 1.2)`；n < 20 时 weight = 1、状态不变（plan §2.5.7）。
- `published → observing`：n ≥ 20，且全站 weight < 0.8 连续 5 个交易日；或（若启用内部评估）复验稳健度 < 发布基线的 70%。
- `observing → published`：weight ≥ 0.9 连续 10 个交易日，且（若启用）复验恢复（**迟滞**：进入阈值 0.8、恢复阈值 0.9，防止来回切换）。
- 提示复审/退役：weight < 0.6 持续 20 个交易日，或复验稳健度 < 基线 50% 持续 20 个交易日 → 通知管理员。
- 因子类上线后：滚动 60 日 RankIC < 发布基线 50% → 进入同一状态机（plan §2.12.1），不另建机制。

### 6.3 本文补充的确定性细则（建议，需架构师确认）
1. **只用已关闭窗口**：统计 T+h 结果时，只计入 h 日窗口已经结束的样本；当日计算、次一交易日生效（避免同日结果影响同日排序）。
2. **统计口径**：健康度用 T+5（波段/短线）或 T+20（中长线）、做T 用 T+1，按卡的 `horizons` 选主跟踪期；不可成交样本不计入 n。
3. **数据原因的观察**：模板必需特征覆盖率 < 90% 连续 3 个交易日 → 显示"数据不足观察"，与表现原因分开标注，**不影响 weight**，也不触发退役提示。
4. **假设被否定**：卡片 `hypothesis.falsified_by` 中可机器判断的条件（如"n ≥ 30 时平滑胜率 < 45% 且平均超额 < 0"）满足 → 通知管理员复审（不自动退役）。
5. **用户层面**：`auto_downweight` 只影响本人排序；RC5 连续亏损暂停属于风控，不属于健康度，二者不要混用。

## 7. 模拟跟踪的绩效评估（A 线）

### 7.1 口径（plan §2.8、§2.8.1）
- 每条 `buy/add/sell/reduce/hold/wait` 记录参考价与基准（默认沪深300，可选行业指数）；T+1/T+5/T+20 收盘后计算区间收益、基准收益、超额、区间最大回撤/最大上涨、是否触发失效条件。
- 方向正确：buy/add 超额 > 0；sell/reduce 超额 < 0；hold |超额| ≤ 阈值（建议初值：T+5 为 2%、T+20 为 5%，需拍板）；wait 只记录、不计胜率。
- 纯模拟，**不代表用户实际收益**；成本可选扣除（默认展示扣费与不扣费两种）。

### 7.2 统计与展示
- 按策略版本 × 周期 × 动作 × 置信度档 × 大盘环境分组。
- 每个指标 `{value, n, window, small_sample}`；胜率附 Wilson 95% 区间，平均超额附 bootstrap 95% 区间（建议），小样本时让用户看到"不确定有多大"。
- 置信度校准：high/medium/low 三档的实际命中率应单调；不单调说明置信度公式需修订（研究侧报告）。

### 7.3 失效条件的效果
- 统计"触发失效条件后"的后续收益，检验失效条件是否真的有用（触发后继续持有的样本超额应更差）。

### 7.4 与实际成交对比
- 用户导入成交后，对比草案参考价与实际成交价：滑点、完成度、延迟。这些数据用来**校准冲击成本分档**（§1.4）。

### 7.5 复盘归因（确定性拆分）
| 部分 | 定义 |
|---|---|
| 市场 | 基准区间收益 |
| 判断 | 模拟超额 = 模拟收益 − 基准收益 |
| 执行 | 实际收益 − 模拟收益（含滑点、未按计划止损、提前离场） |
三者相加等于实际收益；没有实际成交时只显示前两项。

3. 本文 §2–§5 的方法本质上就是历史验证（广义的回测）；若问题 26 不获批，这些方法只能停留在研究员的离线工作，不能进入系统。

### 9.3 建议（需用户/编排者拍板）
- **用户端**：只展示模拟跟踪结果（A 线）和 G6 触发统计；不展示任何历史收益曲线、回测收益或参数优化结果。
- **研究侧**：允许研究员/管理员离线做 §2–§5 的验证（问题 26），用于选默认参数、决定是否晋级、发布后复验；结果只存 `evaluation` schema。

  - 方案 A（建议）：对用户只展示"是否经过内部验证：是/否、方法类型、验证日期"，不展示数值；数值只在管理员视图；
  - 方案 B：完全不展示，字段只对管理员可见。
  两种方案都不违反 §2.12.4，但都需要架构师修改 §2.5.14 G 中"作为 L1 展示字段"的表述。
- 无论哪种方案，`oos_result` 没有执行就写"未验证"，绝不填写未执行的数字。
